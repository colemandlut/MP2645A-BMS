## 3. 变更 ②：R302–R308 = 330k 时的翻转顺序（第 1 轮 P1-2）

### 3.1 计算条件

- **时间常数**：
  - 第 1 级 τ1 = 100k(±1%) × 1nF(±10%) = **89–111µs**；
  - 第 k 级（k ≥ 2）τk = 330k × 1nF = **294–359µs**。
- **阈值**：VT− 在 VCC = 3.0V 时为 0.89–1.20V（LVC p.6）；3.3V 时插值上限约 1.35V，3.65V 时插值上限约 1.53V。
- **漏电**：输入漏电 IIN ≤ ±1µA（LVC p.7，全温度范围）。在 330k 上最多造成 ±0.33V 的偏移，在 100k 上为 ±0.1V。
- **前提**：固件只在所有节 ≥ 3.0V、相邻压差 ≤ 300mV 时才输出 BAL_CLK，所以时钟卡高时同样满足这一条件。
- **翻转时间**：t = τ · ln[(V_hi − V∞) / (VT− − V∞)]，其中 V∞ 为漏电造成的终值偏移。

### 3.2 结果

| 情况 | 取值 | 翻转时间 |
|---|---|---|
| 第 1 级最晚 | V_hi = 3.37 − 0.3 = 3.07V（3V3 取 +2%），VT− = 0.89V，V∞ = +0.1V，τ = 111µs | ln(2.97 / 0.79) = 1.32，约 **147µs** |
| 第 k 级最早 | V_hi = 3.0 − 0.3 = 2.7V（发送节 3.0V），接收节 3.3V 时 VT− = 1.35V，V∞ = −0.33V，τ = 294µs | ln(3.03 / 1.68) = 0.59，约 **173µs** |
| 第 k 级最早（另一角点） | 发送节 3.35V、接收节 3.65V：V_hi = 3.05V，VT− = 1.53V | 同样约 173µs |

- **第 1 级一定最先翻低**，最坏角点叠加最坏漏电时仍有 26µs 余量；不计漏电时余量为 137µs 对 203µs。
- 第 1 级翻低时，第 2 级输入还在不低于 (2.7 + 0.33) × e^(−147/294) − 0.33 ≈ 1.5V，高于 VT−。
- DRV1 的下降沿（≥ 3.0V）把 IN2 推到约 −1.5V，被钳位在 −0.3V，第 2 级立即翻低，然后逐级在 ns 级内**同步带低**第 3–8 级。混相窗口从最长约 50µs 缩短到逐级传播延迟的量级（< 0.5µs），与每个正常时钟边沿相同。

### 3.3 各种情况

- **停时钟**（停在低电平）：最后一个下降沿逐级传播，全部为低 ✅。
- **MCU 复位**（PA8 变为高阻，R52 下拉）：C321 两端节点只有 pF 级对地电容，IN1 瞬间跳到约 −0.15V，是同步的下降沿 ✅。
- **时钟卡在高电平**：按上面的计算，第 1 级先翻，然后同步带低 ✅。
- **MCU 慢掉电**：
  - PA8 随 VDD 缓慢下降，经 C321 高通后在 IN1 上表现为**额外的向下偏移**（斜率 × τ1），第 1 级只会翻得更早；
  - 第 2–8 级不受 BAL_CLK 影响；
  - 掉电复位时的阶跃同样向下 ✅。
- **上电**：各节输入经下拉为 0，全部为低 ✅。
- **正常工作的副作用**：
  - 第 2–8 级的下垂由 6.5% 降到 2.2%，高电平约 2.64V，比 VT+,max 2.08V（3.3V 时）高，余量更大。
  - 空闲时漏电偏移不超过 0.33V，低于 VT−,min 0.89V，仍被可靠地压在低电平。
  - 时钟下限仍由第 1 级（τ1 = 100µs）决定，约 20kHz，不变 ✅。
- **结论**：停时钟、MCU 复位、时钟卡高、慢掉电四种情况都收敛到全低，**持续性混相已消除**，飞电容稳态只承受一节电压（≤ 3.65V）。**P1-2 关闭**。
  - 前提：固件的 300mV 压差门限必须有效。如果接收节 3.65V 而发送节只有 3.0V（压差 650mV），再叠加 −1µA 的漏电，第 k 级最早会提前到约 143µs，与 147µs 相当。这个角点已被固件的 `BAL_MAX_DIFF_MV` 排除，见 P2-2。

## qwen P1-A 裁决（2026-09-28 12:50 JST，Opus 独立复核，只读）

**裁决：不构成 P1，降为 P2（样板实测项），维持现有电路，不建议串电阻。** 同时，qwen 的 P2-9「TI SN74LVC1G17 是反相器」**不成立**。

### 1. 快关路径的实际电流（按拓扑逐段核）

**上升沿（关 P 管）**：U30k.4 → D31k（A→K）→ GPk → Q31k 栅极。

- 回路电阻 = 输出内阻 ro + 二极管动态电阻（约 5Ω）。
  - ro 取 16–29Ω：由 LVC p.6–7 推算，VCC 3.0V 时 VOH 2.3V @ −24mA、VOL 0.55V @ 24mA。
- 驱动电压 = V_cell − Vf。BAT54WS 在 0.1A 时 Vf ≈ 0.7–0.8V（C22629 p.1：VF5 ≤ 1.0V @ 100mA）。
- 负载是 P 管栅极，约 0.75nF（Ciss，QP p.3）到约 1.8nF（按 Qg/V 计入米勒）。

**下降沿（关 N 管）**：经 D30k（A = GN → K = DRV）灌电流。对称计算，N 管栅极约 0.66–1.35nF，所以电流更小。

慢开支路（330Ω）在边沿时只额外叠加约 V_cell / 330Ω ≈ 10mA。

| ro | V_cell 3.0V | V_cell 3.65V |
|---|---|---|
| 16Ω | 110mA | 136mA |
| 24Ω | 79mA | 98mA |
| 29Ω | 68mA | 84mA |

- **峰值约 70–140mA**。qwen 的 85mA 在这个范围内，数量级正确。
- **持续时间**：τ = (ro + rd) × Cg ≈ 21–34Ω × 0.75–1.8nF ≈ 16–60ns。电流高于 50mA 的时间 ≈ τ·ln(Ipk / 50mA)，约 **15–60ns**。
- **每个边沿的电荷**：约 V_cell × Cg ≈ 3–6nC。
- **平均电流**：2 × 3.3V × 1.8nF × 75kHz ≈ **0.9mA**。
- **RMS 电流**：约 110mA × √(150k/s × 35ns / 2) ≈ **5.6mA**。
- **输出级耗散**：≈ ½CV² × 2f ≈ **1.5mW**，SOT-23-5 的温升 < 1°C（θJA 300°C/W，LVC p.4）。

### 2. ±50mA 是直流还是含瞬态

- UMW 手册 p.4 原文是「**DC** Output Sink Current IO ±50mA」，同表还有「**DC** Output Diode Current IOK ±50mA」和「**DC** Supply Current per Supply Pin ICC ±100mA」。三者都是**直流 / 连续**额定，手册没有给容性负载的瞬态峰值。
  - TI 原版的对应条目是「Continuous output current」，语义相同。
- 手册自己的 AC 测试条件就会产生超过 50mA 的瞬态：tpd 在 **CL = 50pF** 下测（p.8），74LVC 边沿约 1–2ns，i = C·dV/dt ≈ 50pF × 3.3V / 1.5ns ≈ **110mA**。可见数十到上百 mA、ns 级的容性充放电峰值，是这类输出的**正常工作状态**，并不违反直流 abs max。
- 与可靠性相关的量是平均电流和 RMS 电流（电迁移）以及结温。本设计分别约 0.9mA 和 5.6mA，温升 < 1°C，**都远低于 ±50mA 和 ±100mA**。
- 另外，qwen 引用的「24mA@3.0V」是 VOH/VOL 的**直流规格测试点**，不是电流上限。

**结论**：「长期超 abs max」的判断把直流额定套用到了 ns 级的容性瞬态上，前提不成立。**不构成 P1**。这条已被本报告第 1 轮 P2-8 覆盖（样板时看 DRVk 波形与 U30k 温升），维持 **P2**。

### 3. 「DRVk 串 10–33Ω」的后果（不建议）

- **串 10Ω**：峰值只降到约 55–100mA，仍高于 50mA，达不到目的。
- **要把峰值压到 50mA 以下**，需要串约 **47Ω**：(3.65 − 0.5) / (16 + 47 + 5) ≈ 46mA。这样快关的 τ 从约 16–60ns 增大到约 50–120ns，P 管关断时间（约 2.7τ）从约 110–165ns 增加到约 **135–330ns**。
- 慢开一侧只由 330Ω 加 47Ω 决定，基本不变：N 管在约 40–80ns 就越过 Vth,min。
- 净效果是**死区被吃掉，重新出现两管同时导通**，正好抵消 U-1 的目的，比现状更差。
- 如果将来实测证明确实要限流，必须**同步放大慢开电阻**，保持「慢开时间常数远大于快关时间常数」，例如串 47Ω 并把 R31k/R32k 由 330Ω 改为约 1k。代价是完全导通更慢（约 5µs，占半周期 6.67µs 的大部分），R_FSL 会明显变差，需要重新核算均衡电流。**不推荐**，只作为样板实测不理想时的备选。

### 4. qwen P2-9「TI SN74LVC1G17 是反相器」

- **不成立。** UMW 手册 p.1 Description 写的是「Single **Non-inverting** Schmitt Trigger Buffer」，p.1 Figure 1 的符号是不带反相圈的缓冲器，p.3 功能表为 A = L → Y = L、A = H → Y = H。
- TI 的命名规则也是 SN74LVC1G17 = 单路施密特**缓冲器**（非反相），SN74LVC1G14 才是施密特**反相器**。
- 本设计的「8 级同相、相位 1 全高、相位 2 全低」正是依赖非反相（规格书 §1.2 引 LVC p.3 函数表），原理图与 BOM 用的都是 1G17（C7394021），**正确**。
