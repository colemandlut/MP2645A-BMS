## P1

### P1-1　D301–D308、D311–D318（1N5819WS）的结电容会吃掉死区，「慢开」失效

- **位置**：D30k（K = DRVk，A = GNk）、D31k（A = DRVk，K = GPk），以及 Q30k.1、Q31k.1。
- **机理**：DRVk 翻转的瞬间，**正要开通的那只管子**的二极管被反偏。二极管的 Cj 与该管栅极电容构成电容分压，DRV 的阶跃会**不经过 330Ω**，直接瞬时耦合到栅极：
  - 上升沿时 D30k 反偏，GNk 被上踢；
  - 下降沿时 D31k 反偏，GPk 被下踢。
- **数据**：
  - 1N5819WS 的 Cj 典型值为 **110pF @ VR = 4V**（Hottech 手册 p.1，C191023；手册不在 `datasheets/`，本次下载到 scratchpad 读的）。0–3.3V 偏置下更大，按电荷平均估计约 150–250pF。
  - 阈值以下的栅极电容取 Ciss：AO3416 为 660pF @ Vds = 10V（QN p.2），3V 时约 750pF（QN p.4 Fig 10）；按 Fig 11 初段斜率则约 1.3nF。AO3415A 为 750pF（QP p.3）。
- **计算**：踢量 = V_cell × Cj / (Cj + Cg) = 3.3 × (110–250) / (110–250 + 660–1300) ≈ **0.26–0.9V**。
  - 对比：AO3416 的 Vth 为 0.45 / 0.7 / 1.0V（min / typ / max，QN p.2），AO3415A 的 |Vth| 为 0.5 / 0.7 / 0.9V（QP p.3）。
  - 所以在低 Vth 的器件上，开通管在 t = 0 就已经越过阈值。规格书 §1.3(b) 按 1.35nF（大信号 Qg/V）算出「只踢 0.2V」和「N 管开通延迟 79–131ns」，这个前提不成立。
- **后果**：
  - 在「另一只管经二极管关断」的约 110–165ns 内，开通管以 Vgs ≈ 0.5–1.0V 导通。按 QN p.4 Fig 7 读，25°C 时 < 0.5A，125°C 时约 1–2A。
  - 估算每节每个边沿 20–50nC，乘以 3.3V、再乘 2 × 75kHz，约 **10–25mW/节**。规格书 §6.2 的目标是 < 5mW，而且这部分耗电在各节之间离散，重新带回了 U-1 想消除的节间偏差。
  - 程度远小于无死区时的 0.1–0.2W，所以定为 P1，不是 P0。
- **建议**（任选其一，封装都不变，SOD-323 焊盘兼容，只改 BOM）：
  - (a) 把 16 只二极管换成**低 Cj 的小信号肖特基**，例如 BAT54WS（C22629，CJ 手册在 `datasheets/`）：CT ≤ 10pF @ 1V，踢量约 0.04V。VF 为 0.24V @ 0.1mA、0.32V @ 1mA，能把栅压拉到低于 Vth,min。IFRM 300mA，IFSM 600mA，可以承受 0.1–0.19A 的关断脉冲。**是否基础库、库存多少，要用 `jlc_api.py` 查**。另外它的引脚要按 CJ 手册核：SOD-323，带色环的一端是 K。
  - (b) 保留 1N5819WS，把「DRV/GN/GP 波形 + 本节直通电流」作为样板的必测项（规格书 §8.3 第 2、3 条），并事先把 (a) 列为预案。
  - 规格书 §1.3(b)、docs/03 §4.3「典型死区 20–50ns」的说法要按上面的结果改正。

### P1-2　时钟卡高 / MCU 掉电时各级异步衰减：混相浪涌超过 AO3415A 的 IDM，规格书只说「可接受的瞬态」

- **位置**：R301–R308、C321–C328，IN1–IN8；影响 X1–X8、Q30k/Q31k、C33k/C34k。
- **触发条件**：
  - BAL_CLK 停在高电平：MCU 死机、IWDG 还没动作，或者 TIM 停在高电平；
  - **MCU 失电**：PA8 随 VDD 缓慢下降，是 ms 级斜坡，经 C321 高通后几乎不产生边沿，效果等同于卡高。
  - MCU 复位时 PA8 变为高阻、R52 下拉。这是**瞬时边沿**：C321 两端的节点只有 pF 级对地电容，IN1 会立刻跳到约 −0.15V，所以复位是安全的，已核。
- **机理**：
  - 每一级的输入以 τk = R30k·C32k 独立衰减，到 VT− 时翻低。第 j 级先翻时，它的下降沿立即把 j..8 级全部带低，但 1..j−1 级仍为高。
  - 于是 CF(j−1) 一端是 X(j−1) = VB(j−2)（经 N 管），另一端是 Xj = VBj（经 P 管），**跨在两节上**，要从 V_cell 被充到 2V_cell。
  - 等上游某一级翻低时，CF(j−1) 又要从 2V_cell 放回单节。
- **窗口长度**：各级的翻转时间 t = τ·ln(V_hi / VT−)。
  - VT− 在 VCC = 3.0V 时为 0.89–1.20V，在 3.65V 时插值为 1.16–1.53V（LVC p.6）；C1523 的容差为 ±10%。
  - 算下来窗口最长约 **50µs**。规格书写的是 30µs。
- **浪涌**：
  - 回路电阻 R_on,N + R_on,P + ESR ≈ 0.08Ω，ΔV = 3.3V。P 管经 330Ω 约 0.3–1µs 进入强导通，电流先受 P 管饱和电流限制，AO3415A 在 −2.5V 时约 30A、−3V 时约 37A（QP p.4 Fig 1）。
  - 两节本地 CB 串联（有效约 25µF）先供电荷，时间常数 τ ≈ 0.08Ω × 20µF ≈ 1.6µs。
  - 峰值约 **20–40A**，超过 AO3415A 的 **IDM 15.6A**（QP p.2），也接近 AO3416 的 IDM 30A（QN p.1）。每次事件的能量约 ½·C·ΔV² ≈ 0.5mJ，进入和退出各一次。
  - **本地电源**：进入时相邻两节的本地轨共下陷约 2.6V（CB 与 CF 电荷分享：3.3 × 100/125）。退出时 CF 以约 6.6V 对单节 CB 放电，本节轨瞬时冲到约 (100 × 6.6 + 50 × 3.3) / 150 ≈ **5.5V**。这个值没超过 LVC 的绝对最大值 7V，但已顶到推荐上限 5.5V（LVC p.4、p.5）。
  - 此外 CF 在窗口内承受 6.6–7.3V，高于额定 6.3V。
- **判定**：单次大概率不会损坏，但属于「超出手册额定」的重复性应力。每次死机或非正常掉电都会发生一次，与规格书 §1.4(b)「可以接受的瞬态」的定性不符。
- **建议（只改阻值，不改拓扑）**：**让第 1 级永远最先衰减**。第 1 级一翻低，它的下降沿会在 ns 级内把 2..8 级同步带低，混相就被消除了。
  - **推荐**：R302–R308 由 100k 改为 **330k**，R301 保持 100k。
    - 第 1 级最晚翻转时间：110µs × ln(3.0 / 0.89) ≈ **133µs**。
    - 其余各级最早翻转时间：297µs × ln(2.7 / 1.53) ≈ **169µs**，余量足够。
    - 330k 的漏电偏移：±1µA × 330k = ±0.33V，仍低于 VT−,min 0.89V。
    - 下垂变小，对阈值余量更有利。
    - 需要取 330k 0402 的料（嘉立创 C 编号用 `jlc_api.py` 查，不要凭记忆写）。
  - **备选**：R301 改为 33–39k，或 C321 改为 330pF，但这样 75kHz 下第 1 级的下垂会增大到约 18%。第 1 节为 3.65V 时，高电平约 2.4V，VT+,max 约 2.28V，余量只剩约 0.1V，而且把时钟下限抬到约 60kHz，**不推荐**。
  - 固件 X-5 的第 ② 条（停时钟停在低电平）仍然要做（见 P2-6）。

## P2

1. **P2-1　U301–U308 的手册自相矛盾（C7394021 UMW）**：p.2「Pin Function」表写 SOT23-5 为 **4 = VCC、5 = OUT**，DFN6 表也把 VCC 和 OUT 对调了。p.1 Figure 1 的引脚图写的是 **4 = OUTY、5 = VCC**。
   - 原理图与嵌入符号取 4 = OUTY、5 = VCC，与 p.1 图、TI 原版 DBV 封装以及嘉立创符号一致，**判定原理图正确**。p.2 表格应是手册的笔误。
   - 建议写进知识库，样板到货后用万用表的二极管档核对一颗（VCC 与 GND 之间有 ESD 结构）。
2. **P2-2　IN1 正向瞬态没有钳位**：规格书 §1.4(c) 只核了 VB0 与 GND 之间的**负向**地电位瞬变（IIK −50mA，LVC p.4）。
   - 74LVC 输入端**没有到 VCC 的钳位二极管**，VI 的绝对最大值是 7V，与 VCC 无关（p.4）。GND 相对 VB0 的正向瞬变（短路关断时的 L·di/dt，规格书自己估的是「几伏到几十伏」）会经 C321 几乎原样加到 IN1 上，只由 R300 1k 限流。
   - 建议评估：给 IN1 加一只到 VB1 的低 Cj 肖特基（A = IN1，K = VB1），正常工作时高电平约 3.0V，低于 VB1 + Vf，不会导通；或者给 R300 留一个可调位。
   - k ≥ 2 的各级没有这个问题：它们的节点 dv/dt 受 100µF 的 CB 限制，而且 LVC 有 Ioff 部分掉电保护（p.7，IOFF ≤ 10µA）。
3. **P2-3　级间传播延迟带来的「跨级重叠」没有计入**：DRVk 带着约 1.8nF 的栅极负载（经二极管），边沿约 45ns，经 C32(k+1) 到下一级约有 40ns 延迟。
   - 上升沿时，Q30k 开始导通，而 Q31(k+1) 还没关断，CFk 会短暂跨接两节。下降沿时，Q31k 已经开通，而 Q30(k+1) 还没关断，CFk 会被短接。
   - 这部分电流同样受「开通管刚过阈值」限制，量级估计在 mA 到 A 之间，与 P1-1 叠加。
   - 建议列入 §8.3 样板实测：同时测相邻两级的 DRV 和 CFk 电流探头波形。
4. **P2-4　原理图可读性（PDF 第 4 页目视）**：
   - C301–C308 的位号「C30k」与 `VBk` 标签文字、值「100nF 16V」互相重叠（每节都有）；
   - Q311–Q318 的 P 管符号镜像后，「AO3415A」「Q31k」两段文字倒置显示；
   - 标题栏为 Rev `v0.3-draw-r1a`、Date 2026-09-26，与快照 r1 和实际日期不一致。
   - 均属规则 00 ③，不影响网表。
5. **P2-5　手册缺件**：任务书列出的 1N5819WS（C191023）手册**不在 `datasheets/`**，本次是下载到 scratchpad 核的：SOD-323，带色环的一端是负极，与封装丝印的阴极条在焊盘 1 一侧一致。建议主代理用 `tools/fetch_datasheets.py C191023` 补进来。
6. **P2-6　硬件的安全态依赖固件 X-5 ②③，而固件没有实现**：`firmware/src` 里只有 `bal_clk` 逻辑标志，没有 TIM1/PA8 的空闲电平配置。规格书已列为 X-5（P1、固件），这里只提醒：P1-2 改完后仍要保证「停时钟停在低电平」。
7. **P2-7　均衡电流口径 0.16A@100mV 复核**：
   - 独立重推 6·R_w：边线各 I，中线 2I，折算为 ΔV' = ΔV − I(R + 4R + R)，✅。
   - R_FSL = 4·(R_N + R_P + ESR)：每相两只同型管，占空比 50%，按 Σ a²R/D 推导一致 ✅。
   - 我另外做了时域仿真：两节，CB 为 50µF 有效，CF 为 100µF 有效，R_w 45mΩ，N/P 为 20/42mΩ，75kHz。结果 **I ≈ 0.164A @ 100mV**，与公式的 0.159A 吻合，公式略偏保守。
   - 前提提醒：这是「单独一对相邻节」的口径。8 节同时工作时，各 CF 通过共用的半桥耦合，单个高节会同时向两侧放电，此时的电流不能直接套这个口径。C_eff = 100µF 仍待样板实测。
8. **P2-8　既有 P2 确认**（规格书已列，这里只确认数值）：
   - 74LVC 关断方向的峰值电流 0.1–0.19A，超过 IO ±50mA 和 ICC ±100mA 这两个直流绝对最大值（LVC p.4），瞬态属于常见用法，样板看温升。
   - BAL_3A 的 1.2mm 线宽对 SOT-23 焊盘偏宽，布局时再建 0.6mm 的类。
