## 0. 本页概览

33 器件、131 脚、113 段导线、7 个 junction、19 个 U6 NC 标志 + 1 个 U7.5 NC 标志。
版面（spec §9）：左 = 电源/时钟/复位（去耦列 C50–C55 + 偏置列 C58/R50–R52 + 晶振组 Y1/C56/C57）；
中 = U6 CH32V203C8T6；右 = CAN 链（J7→U8→R55→JP1→R56/R57‖L2→U7，差分对 CAN_H/CAN_L 平行）+ U7 外围 R53/C59/R54 + J8 调试口 + LED1–3/R58–R60 + SW1。

**用户决定全部落实**：RS485 不画（PA2/PA3/PA4 放 NC）；J8 1×6 2.54mm DNP（`(dnp yes)`，针序 3V3/SWDIO/SWCLK/GND/TX/RX）；
R55 120Ω 串 JP1 跳线做终端（插帽接入/拔帽不用）；SW1=用户键（PB12，KEY）；CAN 待机超标接受（不加断电 MOS）；
晶振负载 33pF C1562（C56/C57）；J7 针序 1 CAN_H / 2 CAN_L / 3 GND / 4 GND；绿灯 330Ω C25104（R60）；PWR_EN 删除；
L2 共模电感 C95572 DNP + R56/R57 0Ω 旁路默认贴。
