## 4. 电芯采样 RC（Figure 28、串阻功耗/封装、CELL 与 BAL 分离）

**通道语义**（独立推导 + 规格书 L369/L689-702 + 手册 p.6）：cell k = 自 BAT− 端起第 k 节（cell 1 邻 BAT−，cell 8 邻 PACK+）；VC0 = cell 1 负极抽头（≈0V，经 R201 33Ω + D201 3.3V 稳压接 J5.5 的 CELL0 线，**不直连 GND 网络**——保留线束连接监测与过压保护路径）；VC1…VC7 为节间节点；VC8 = cell 8 正极 = PACK+。

**均衡电流路径（Figure 28，p.125）**：芯片内置均衡管跨在 Cn 与 Cn−1 两脚之间、位于两侧 RCELL_FLT **之后** → 均衡电流流经 2×RCELL_FLT，不流经 CCELL_FLT（稳态被电容隔断）。

**最坏工况推导**（LFP 单节最高 3.65V，Ron 取 p.13 范围最小 15Ω → 电流最大）：

```
I_max = 3.65V / (2×33Ω + 15Ω) = 3.65 / 81 = 45.1 mA
P_每只串阻 = 45.1mA² × 33Ω = 67.3 mW
```

- **0805（C17634）**：额定 125mW@70°C，85°C 降额后 ≈103mW → 67.3/103 = **1.5× 余量** ✓
- 0603 对照：85°C 降额后 82mW → 余量仅 1.22×（<1.5）→ 规格书弃 0603 用 0805 的论证**成立**
- 同一时刻只均衡奇数或偶数节（p.126）→ 最多 2 只 33Ω 同时满载，各 67mW，无叠加问题
- C201–C208 电压应力 = 相邻 VC 差 = 单节 ≤3.65V，50V 额定余量巨大 ✓
- CELL（J5，被动均衡 45mA 级）与 BAL（J6，均衡主回路）分线束、分极柱 ✓（docs/03 §2.4，安培级均衡电流不上采样线）

**D201 保护路径核算**：正常 VC0≈0V，3.3V 稳压管不导通，P≈0；若 CELL0 线束误接高压（如 29.2V），(29.2−3.3)/33Ω ≈ 785mA → R201 瞬耗 2W（0805 秒级熔断）、稳压管同时损坏——两只牺牲件保护 C0 引脚（差分应力钳在 3.3V）。与 Fig 27 DAGND-C0 设计完全一致，属保护路径而非缺陷。

## 6. 极性件核对（D201、Q201）

**D201（BZT52C3V3，C353528，SOD-123）**：K→VC0、A→GND。稳压管阴极接被保护节点（VC0）、阳极接 GND → 钳制 VC0 ≤ +3.3V，**极性正确**（Fig 27 DAGND-C0 同向）。故障路径核算见 §4。

**Q201（MMBT5551，C2145，SOT-23，NPN，VCEO=160V，Pd=300mW@25°C）**：

## 11. 对规格书本身的质疑（含 §12.1b 用户决定）

1. **ΣCiss 双依据（→P1）**：规格书 L466 写 "Ciss 14.49nF×6=87nF→100nF"，BOM C226 注又写 "Qg 等效 144nF 超 Table 22 范围"。独立验证：Tokmas 手册 p.3 **Ciss = 14490pF @VGS=0、VDS=50V**（静态参数）→ 6×14.49 = 86.94 ≈ 87nF，落在 Table 22 最大行（100nF）内 → **C219 100nF 按手册自身方法合规**；Qg = **240nC** @VDS=50V/VGS=10V（注：知识库旧值 178nC 有误，本次已修正）。"144nF" 的来源未能在手册静态参数中重现（Qg/Vgs = 240nC/10V = 24nF ≠ 144nF；疑为 Ciss 曲线其他工作点读数，**未逐项重推**）。两份文档必须统一，且需样板实测裁决（P1）。
2. **5mA REGIN 前提（→P2-10）**：规格书 §9.2 自述"手册没有给工作模式下 REGIN 的电流"。本次全文复核确认：p.8 EC 表仅关断 1µA / 安全模式 23µA；p.6/7/13/32 均无工作电流规格（p.32 仅"REGIN (5V): supplies power to the AFE"）。5mA 为保守估算（对 3mA 估算余 67%），Q201 108mW 核算成立、BCX56 替代在 BOM。**规格书的诚实披露值得肯定，但"实测 REGIN 电流"必须列入样板任务**，否则 Q201 选型停留在假设上。
3. **3V3 脚（26）未接 MCU（→P2-9）**：p.6 明确 3V3 为**输出**（"drive external peripherals"），p.32 意图是 "powers an external MCU"。本设计 AFE_3V3 只挂 C215（空载），MCU 用 04 页 +3V3。合规（旁路电容齐备）但偏离手册意图：空载时内部 3.3V 调整器精度/静态电流可能劣化——因本版无负载，无功能影响，注记即可。
4. **RSENSE 0.1mΩ（§12.1b 0e 用户决定，→P2-5）**：低于 Table 18 的 0.2–5mΩ（p.124 电流量程亦按 0.2/2/5mΩ 档位设定）。0.1mΩ 不在手册档位内 → 固件须用 0.2mΩ 档位寄存器并把读数 ×0.5 换算，电流 ADC 有效分辨率减半。规格书已记录（保护阈值按 0.1mΩ 重算 + NTC_SHUNT 温补），**判为可接受的用户决定**，注记固件实现时必须落实档位换算。
5. **D_BATT 缺失（→P2-1）**：Fig 27 图上有 BAT+ 侧钳位稳压管，Table 18（必备件清单）无对应行——规格书未点名该件。设计缺之。因 BAT+ 网络已有 D3 SMDJ33A + F11，VTOP 脚绝限 86V ≫ 53V 钳位，风险被覆盖；**但规格书应补一句"D_BATT 由 01 页 TVS 替代覆盖"的明示**，免得后人对照 Fig 27 时误判漏件。
6. **NSHDN 上拉推导（L558）**：规格书推导与本人独立推导一致（3.29V > 2.65V，悬空=关断故上拉必需）——**无异议**。

8. **C_CELL "9 只"已改 8 只**（L31/§3.2）：8S = 8 个相邻节间电容，修正正确 ✓。
