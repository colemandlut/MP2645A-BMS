  - **P 慢开**：R32k 放 750pF(+Cj)：τ≈0.28µs；**P 快关**：D31k 钳 GP=DRV−Vf 跟上升沿（~5ns 级）。
  - **重叠（DRV 下降沿）**：N ~40ns 关断、P ~70ns 起「基本导通」（~400ns 全导通）→ 重叠 ~30–350ns，Thevenin 峰值 ~10–20A，实际被电芯 ESR + 线束 0.7µH 限流 → 每边沿 ~0.3–1µJ ×75k/s → **10–80mW/级**（P2-1，样机/SPICE）。上升沿无重叠（N 慢开时 P 已快关）。
- **电容分压（P1-B 重推）**：Cj 与栅电容并联分压，DRV 边沿馈通 ΔV·Cj/(Cj+Ciss)：N 栅 +0.47V@3.3V（发生于 N 慢开启动点，此时 P 已关 → 短暂 10–30mA 提前导通，µW 级，无碍）；P 栅 −0.42V（DRV 下降沿）→ Vgs_P≈−1.4V，仍低于 \|Vth\|max 0.9V 达 0.5V → P 不提前通。**结论：r1 的 Cj 问题是「边沿提前 ~10–30ns」，非持续直通；r2 换 BAT54WS（CT≤10pF → 馈通 0.03–0.05V）有效，独立核实见 §8。**

### 3.3 U30x 输出峰流（P1-A，开放）

- 路径：DRVk 边沿 → 死区二极管（ro_d≈0.2–0.3Ω@100mA）→ 栅。上升沿：P 栅（750pF/Qg 9.5nC）经 D31k 充电：I_peak ≈ (DRV_high−GP_start−Vf)/ro_out ≈ (Vcell−0.7−0.45)/24 ≈ **85mA**（3.3V 角）；下降沿：N 栅经 D30k 放电：≈(2.75−0.75)/24 ≈ **83mA**；持续 ~13–18ns（tpd ~5ns + ro×C 16–18ns），**每个边沿**（75kHz×2）×8 级。
- 对照 UMW 手册：**绝对最大 IO = ±50mA（p4 Absolute Maximum Ratings）**；Features 保证 24mA@3.0V（p1）。峰流超 abs max ~70–110%：端点电压由二极管钳位、与 ro 无关 → **功能正确，但长期超出绝对最大额定 = 可靠性降级风险**（该器件 75kHz 永久工作，非偶发脉冲）。
- 处置建议：(a) 样机实测 U30x 输出电流峰（栅极电流探头/示波器）；(b) UMW/UTD 书面确认脉冲能力；(c) 若实测 >50mA：DRVk 串 10–33Ω（峰流降至 <50mA，重核慢开 τ 仍 ≪3.35µs ✓，D30k/D31k 钳位端点不变）。
