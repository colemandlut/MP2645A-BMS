## P2（11 条，交用户定夺）

### P2-1 Y1 激励功率：规格书的前提不成立，33pF 会把激励功率抬高约 2.4 倍

- **规格书的推导**：§2.4 用 CH32 p.46 Table 4-11 的「HSE drive current 0.53mA @20pF」当作流过晶体的电流，算出 P = 80 × 0.53² ≈ 22µW。
- **问题**：这个 I2 是振荡器自身的耗电（与 STM32 数据手册同一格式的参数），不是晶体的 RMS 电流。所以这个前提不成立。
- **正确的估算**：激励功率 ≈ ESR × (2πf · C_L2′ · Vrms)²。
  - 取 C_L2′ ≈ 33 + 4 pF，OSC 脚幅值 1Vpp 时约 78µW；2Vpp 时约 310µW，**超过 XTAL 的 DL 上限 200µW**（XTAL p.1）。
  - 负载电容从 20pF 改到 33pF，同幅值下激励功率约升 (37/24)² ≈ 2.4 倍。
  - CH32 手册没有给 OSC 脚的幅值，不能算定。
- **建议**：
  - 在 OSC_OUT 与 Y1.3 之间预留一颗 0402 0Ω 串联电阻（Rext，C17168，基础库，零上料费），样板实测幅值后再定值；
  - 或者至少在样板阶段测一次晶体电流。
- **33pF 这个选择本身是对的**：CL = 16.5 + 杂散 2–7pF（CH32 p.47）= 18.5–23.5pF，把 20pF 包在中间 ✅。
  - 起振裕量已复核：gm_crit = 4 × 80 × (2π × 12M)² × (23p)² = 0.96mA/V，手册 gm = 17.5mA/V（CH32 p.46），裕量 18 倍 ✅。
  - 规格书 +34ppm 的频偏估算里 C1 = 5fF 是假设值，手册没给。好在 CAN 的时钟容差是 0.1% 级，这个数只作参考。

### P2-2 R55 功耗：规格书用典型值，最坏工况余量只有约 1.1 倍

- **规格书**：§3.4 按 VOD = 2V（典型）算出 33mW，得出「余量 3 倍」。
- **按最大值算**：HVD p.5 的 VOD(D) 最大是 3V，P = 3² / 120 = **75mW**。
- **为什么要按连续显性算**：这颗 HGSEMI 收发器没有 TXD 显性超时（手册里找不到 dominant time-out）。固件把 PA12 卡在低电平时，总线会一直处于显性，R55 连续承受上述功率。
- **降额**：0603 额定 100mW 在 70°C 以上线性降额，85°C 时约 82mW，**余量约 1.1 倍**。
- 结论：仍在额定内，0603 不必改；但规格书的「3 倍」应订正。固件要避免 TXD 被长时间拉低。R53 已经保证复位时为隐性。

### P2-3 U8 PESD2CAN 的额定值与 8S 系统的关系

- 击穿电压：VRWM = 24V，VBR = 26.1–30.2V（ESD p.3）。8S LFP 满充 29.2V，**如果线束把 CAN 线误接或短到 PACK+，U8 会持续击穿并烧毁**。
- 钳位电压：41V@5A（ESD p.3），比 HVD 总线脚的绝对最大值 ±40V（HVD p.4）高 1V。
- J7 只有 CAN 和 GND，线束里没有 PACK+ 时风险很低。规格书 §3.3 已经记录并接受了钳位这一点，这里补上误接 PACK+ 的场景，交用户确认线束。

### P2-4 J8 上的 USART1 做不了 ISP 下载，前提缺 BOOT0

- **规格书说法**：§1.2 称「WCH 的 ISP 引导程序也走 USART1」。
- **问题**：进入 System Boot 需要 BOOT0 = 1。现在 BOOT0 只有 R50 10k 下拉，J8 上也没有 BOOT0，所以串口 ISP 实际用不了。另外 NRST 也没有引出。
- **影响**：SDI（SWDIO/SWCLK）下载不受影响。
- **建议**：给 BOOT0 和 NRST 各加一个测试焊盘（不花钱）。或者在规格书里订正为「J8 的 TX/RX 只作调试打印」。

### P2-5 规格书的手册页码与引用订正

- **漏电流、弱上拉/下拉表的页码**：Table 4-19（Ilkg 1µA/3µA，RPU/RPD 30–50k）在 **CH32 PDF p.49**，规格书写的是 p.50。p.50 是 Table 4-20 和 NRST 表。
- **CAN 显性电流**：「显性 ≈35mA（HVD p.5，加 60Ω 负载）」这个数不在 HVD p.5 上。p.5 只给了空载 ICC 1–2mA，35mA 是 2V/60Ω 推算出来的，应注明「推算」。
- **VDDA 必须与 VIO 同压**：依据实际在 CH32 p.14–15（§2.5.3）和 p.39 Table 4-2 两处，结论正确。
- **BAL_CLK 安全态**：规格书写「VT− 约 0.6V 量级」，已按 LVC 手册核实为：
  - VT− 最小值：VCC = 2.3V 时 0.56V，VCC = 1.65V 时 0.35V（LVC p.6）；
  - 输入漏电流 ±1µA（LVC p.7）。
  - 最坏情况 (3µA + 1µA) × (100k ∥ 1M) = 0.36V < 0.56V ✅，结论成立。
  - 但如果电芯低到约 2V，VT− 最小值会低于 0.36V。此时只剩 BMS 的欠压保护兜底，影响很小。

### P2-6 绿灯 LED3 电流余量偏薄

- LEDG p.3：VF = 2.6–3.1V @5mA。
- 330Ω 时 I = (3.3 − 0.1 − VF) / 330 ≈ 0.6–2mA（VF 在小电流下取 2.5–3.0V），单板之间亮度可能差约 3 倍。
- 规格书已经把 1k 改为 330Ω，方向正确。如果嫌暗，可以再降到 220Ω（C25091，要先核是否基础库）。低优先级。

### P2-7 固件注意：TIM1 的互补通道与 LED/按键脚复用

- PB13、PB14、PB15 是 TIM1_CH1N、CH2N、CH3N，PB12 是 TIM1_BKIN（CH32 p.25、p.37）。
- BAL_CLK 用的是 TIM1_CH1（PA8），固件**不得置 CC1NE、BKE**，LED 脚保持 GPIO 模式；否则 PB13 会输出互补 PWM，或者按一下 SW1 就刹停均衡时钟。
- 建议补进规格书 X-5。

### P2-8 可读性小项（不算重叠）

- Y1 的数值「12MHz」离本体约 10mm，孤零零放在下方，应挪到 Y1 旁边。
- U7 左侧的 `CAN_RXD` 局部标签与 `+3V3` 全局标签几乎贴边，应拉开 1 格。
- 「L2 与 R56/R57 二选一」写了两次（页头说明和 L2 旁），留一处即可。
- 规格书 §9 要求加的注释「I2C 上拉 R_I2C1/2 在 02 页」没有单独写。页头只写了「I2C1 PB6/7→02 页 MP2797」。

### P2-9 L2 的 Value 字段里带了「(DNP)」

- L2 的 Value 是 `51µH CMC (DNP)`，BOM 第 79 行是 `51µH`。DNP 应当只用属性表达，Value 与 BOM 保持一致，否则 BOM 对账会报差异。
- 另外，J8 和 L2 都是 `in_bom yes` 加 `dnp yes`。出嘉立创 BOM 时要确认 `jlc_fab.py` 会剔除 DNP 件。

### P2-10 工程其它位置还有残留

- `tools/gen_kicad_skeleton.py` 第 48、50 行的 SHEETS 契约里还有 `RS485_A`、`RS485_B` 和「RS485 可选」。
- docs/03 §6「去耦」一行还写着「【VDD 脚数待手册】」，应按规格书关闭为 N = 5（VBAT、VDDA 和 3 个 VDD）。

### P2-11 KiCad 不会把 CAN_H / CAN_L 识别成差分对

- KiCad 的「布线(差分)」只认 `_P`/`_N` 或 `+`/`-` 后缀（规则 0c 第 1 条）。
- 契约名是用户定的，不建议改名。布线时可以按网络类手动等长，或者只在 PCB 侧另起别名。在这里记一笔，免得到布线时才发现。

- 封装：焊盘 1（−1.1, +0.85）、2（+1.1, +0.85）、3（+1.1, −0.85）、4（−1.1, −0.85），与手册顶视图的 #1 左下、#2 右下、#3 右上、#4 左上一致 ✅。
- 负载电容：CL = 16.5 + 2–7 = 18.5–23.5pF，包住 20pF ✅。ESR 在 12MHz 档最大 80Ω，C0 最大 3pF ✅。

### L2 ACT1210-510（CMC p.3 Circuit Diagram）/ R56 / R57

- 手册：绕组 1–4 为一路、2–3 为另一路，1、2 在同一侧（同名端）。
- 实况：
  - L2.1 接 CAN_H_X，L2.4 接 CAN_H；
  - L2.2 接 CAN_L_X，L2.3 接 CAN_L；
  - 两路绕组同向，是共模接法 ✅（接成 1→4 与 3→2 就会变成差模扼流，那样是错的，这里没有）。
- 封装：焊盘 1、2 在同侧，间距 1.0mm；1 对 4、2 对 3 隔着本体，间距 3.14mm；外形 4.29 × 1.15 与推荐焊盘 4.1 / 2.0 / 0.6 相符 ✅。有 1 脚丝印点 ✅。
- R56 跨接 CAN_H_X 与 CAN_H，R57 跨接 CAN_L_X 与 CAN_L，都是 0Ω，与 L2 二选一 ✅。L2 为 DNP ✅。
