## P0 不能投板

### P0-1　本页 10 个符号实例都没有 `Footprint` 字段，网表里的封装全部为空
- **位号**：U4、F11、C40、C41、C42、C43、D7、L1、R40、R41（全部）。
- **证据**：快照 `netlist.xml` 和复跑的 `/tmp/opus04_net.xml` 中，这 10 个 `comp` 都是 `<field name="Footprint"/>`（空），也都没有 `<footprint>` 元素。原理图里各实例只有 `Reference / Value / LCSC` 三个属性，`Footprint`（和 `Datasheet`）只写在嵌入的 `lib_symbols` 里。KiCad 从实例字段取封装，不会回退到库符号的默认值。
- **后果**：「从原理图更新 PCB」（F8）时 10 个器件都找不到封装，PCB 上一颗也放不上。BOM/CPL 也会缺 `Footprint` 列。ERC 不报这个问题（`footprint_link_issues` 只在字段非空时才检查），所以要靠网表判读。
- **改法**：生成脚本给每个实例写 `(property "Footprint" "jlc:…")`，取值和 `jlc.kicad_sym` 中对应符号一致（U4 `jlc:SOT-23-6_L2.9-W1.6-P0.95-LS2.8-BR`、F11 `jlc:F1206`、C40 `jlc:CAP-SMD_BD6.3-L6.6-W6.6-LS7.3-FD`、C42 `jlc:C1210`、C41 `jlc:C0402`、D7 `jlc:SMA_L4.3-W2.6-LS5.2-RD`、L1 `jlc:IND-SMD_L5.0-W5.0`、C43 `jlc:C0805`、R40/R41 `jlc:R0402`），`Datasheet` 顺便补上。改完重导网表，确认 10 个 `<footprint>` 都不为空。其它子图如果用的是同一个生成器，要一并检查。

## P1 必须改

### P1-1　删 D6 的前提「BAT+ 最坏 ≈53V」在 SCP 关断时不成立。VIN_F 需要本页自己的限幅，建议用串联电阻 + C40 做 RC，不是把 D6 加回来
- **位号/网络**：F11 → `VIN_F`（U4.5 VIN、C40.1、C42.2）。上游依赖 01 页的 D3（SMDJ33A，BAT+→BAT-）。
- **前提 1：D3 还不在图上。** 复跑的整工程网表只有本页 10 个器件，01 页是空的，根图 ERC 报 `isolated_pin_label: Global Label 'BAT+'`。所以「D3 已钳位」目前无法验证，只能作为跨页依赖记账。
- **前提 2：53V 是 SMDJ33A 在 IPP = 56.3A 时的 VC**（`C438163_SMDJ33A_晶导微.pdf` 第 2 页表 1：VBR min 36.7V，VC 53.3V @ IPP 56.3A，10/1000µs）。但详细设计 §2.2 D3 一行自己写明 D3 要承担「800A 下 ½LI²（L=1µH）」。关断瞬间电池侧电感的电流全部转入 D3 与 FET 雪崩通路：
  - 按表内两点外推，动态电阻 Rd ≈ (53.3−36.7)/56.3 ≈ 0.29Ω。要守住 VIN ≤ 60V（DS p.4 §7.3 推荐工作上限；p.4 §7.1 绝对最大 65V），D3 电流不能超过 (60−36.7)/0.29 ≈ **80A**（65V 对应约 96A）。
  - 要让 D3 电流始终低于约 80A，800A 的下降时间要 ≥ L·ΔI/(Vclamp−Vcell) = 1µH×800A/(53−29) ≈ **33µs**。本设计为了快关特意加了 PNP（§2.2，τ ≈ 1.5µs），实际 di/dt 要高一个数量级，BAT+ 会被推到 D3 大电流区或 DSG 管雪崩电压（IPT012N08N5 为 85V 级）附近，**超过 LMR16006 的 65V 绝对最大**。
- **把 D6 加回来也没用**：D6 在 F11 之后、与 D3 并联在同一个尖峰上，它会经 F11（冷阻 0.075Ω，`C151135` 第 1 页）分走大电流，结果是 F11 或 D6 自己先坏。
- **建议（本页内就能闭合，与 01 页实现无关）**：F11.2 与 C40/C42/U4.5 之间串 **R = 10Ω**（抗浪涌/脉冲额定型，建议 2512 或 1206 抗浪涌系列，由取料方核脉冲曲线），和 C40 组成 RC。
  - **与 TVS 行为无关的上界**：电池侧电感上多出来的伏秒恒等于 L·I = 1µH×800A = 800µV·s。电容上的抬升 ΔV ≤ L·I/(R·C) = 800µ/(10×47µ) ≈ **1.7V**；R = 4.7Ω 时为 3.6V。
  - **计入 C40 的 ESR**（手册缺，按 0.5Ω 估）：即使 BAT+ 冲到 270V，VIN_F ≈ 29.2 + (270−29.2)×0.5/10.5 ≈ **40.7V** < 60V ✅。
  - **稳态代价**：<80mA 负载时，输入平均电流 ≈ 3.3×0.08/(0.8×20V) ≈ 17mA，压降 0.17V，损耗 3mW。按 LMR16006 满 600mA 算：0.12A → 1.2V、0.14W，对 UVLO 4V（DS p.5）没有影响。
- **文档联动**：§5 写的「53V < 绝对最大 65V」应改成「VIN_F 在 RC 后 ≤ 约 41V < 推荐 60V」。D3 的 IPP 与 SCP 关断速率之间的矛盾留给 01 页复核（D3 会同时威胁 MP2797 的 BAT 脚与 C11–C14），本页用 RC 自保。

### P1-2　F11（0466001.NRHF）直接挂在电池源上，分断能力和上电脉冲都不够
- **位号/网络**：F11，`BAT+` → `VIN_F`。
- **分断能力**：手册第 1 页，1A 档的额定电压 63V、分断能力 **50A @ 63V**、冷阻 0.075Ω。BAT+ 在主保险 F1 和 MOSFET 之前（§2.1 拓扑图），本支路上游没有别的限流。只要 C42、C40 或 U4 的 VIN–GND 短路失效，预期短路电流 ≈ 29.2V/(0.075 + 走线约 0.01 + 电池约 0.005Ω) ≈ **320A**；53V 时约 590A。这是分断能力的 6–12 倍，超额分断可能拉弧或炸裂，保险丝不能可靠断开。
- **上电（热插拔）I²t**：从 0 阶跃到 V 给 C 充电，流过保险丝的 I²t = V²C/(2R_total)。
  - C42：有效约 2µF（见 P2-6），只经过 F11 → 29.2²×2µ/(2×0.075) ≈ 0.011 A²s。
  - C40：47µF，ESR 取 0.5Ω → 29.2²×47µ/(2×0.575) ≈ 0.035 A²s。
  - 合计约 **0.046 A²s**，已超过手册第 1 页 1A 档的额定熔化 I²t **0.0423 A²s**。每次接电芯都可能熔断，或者累积疲劳。
- **改法**：采用 P1-1 的 10Ω 串阻后：
  - 短路电流 ≤ 53/10 = 5.3A，远低于 50A 分断能力；5.3A 是额定的 530%，按手册表「300% → ≤0.2s」快速熔断。
  - 上电 I²t = 29.2²×49µ/(2×10.6) ≈ **0.002 A²s**，约为熔化 I²t 的 5%。
  - 电阻要承受熔断前的能量 ≈ I²t_clear×R ≈ (0.04–0.1)×10 ≈ 0.4–1J，这决定封装（2512/抗浪涌），由取料方按电阻脉冲曲线核。
  - 如果不加电阻，就必须换一个分断能力 ≥ 600A @ 63V 的保险丝，1206 薄膜保险丝做不到。

## P2 建议

**P2-1　SHDN（U4.4）悬空，与手册 Figure 9 的 100k 上拉不同**
- 手册允许悬空：DS p.3 Pin Functions「Float to enable」，p.9 §8.3.4「can be enabled even if the SHDN pin is floating」。
- 悬空时唯一的上拉是约 −4.2µA 的内部电流源（DS p.5，SHDN = 2.3V），门限 1.05–1.38V。这个节点在 SW 开关沿（约 30V/10ns）下容易受耦合。
- 不建议照搬 Figure 9 的 100k 接 VIN：手册没有给出 SHDN 内部钳位电压，常开时的静态电流无法核算，可能吃掉待机预算（目标 < 300µA）。
- 建议：SHDN 保持悬空，但加一只 **1–10nF 电容到 GND**（4.2µA 充 10nF 到 1.25V 约 3ms，软启动可以接受）。同时按 §5 的【待定】给运输模式预留 NMOS 下拉焊盘（DNP）。PCB 上 SHDN 走线要尽量短，并远离 SW_3V3。

**P2-2　R40/R41 可以放大 10 倍，省待机电流**
- 分压电流 3.3V/43kΩ = 77µA（在 +3V3 上）。折算到 BAT+（ECO 效率按 65% 估）≈ 77µ×3.3/(29.2×0.65) ≈ **13µA**，占 300µA 预算约 4%。
- 改成 330k/100k（手册 R2 推荐 1k–100k 的上限，DS p.9 §8.3.3）只剩约 1.3µA，Vout 不变：0.765×(1+3.3) = 3.29V。
- 代价是 FB 节点阻抗变高，PCB 上要紧贴 U4.3（DS p.17 布局第 1 条）。
- 用户看重待机时可以采纳，否则保持现状也可以。

**P2-3　+3V3 对地短路时 D7 超过结温**
- 输出短路时 U4 以峰值限流 1.2–1.7A（DS p.5）持续工作，D ≈ 0，电感电流几乎全部从 D7 续流。
- P ≈ 1.5A × 0.75V ≈ 1.1W。SS210 的 RθJA = 80°C/W（`C14996_SS210.pdf` 第 1 页，条件是 5×5cm 焊盘），温升约 90°C，45°C 环境下 Tj ≈ 135°C，超过 **Tj max 125°C**。U4 自身导通损耗很小，不会触发 170°C 过热关断，因此不会自己停。
- 建议：D7 两端铺足铜（阳极接 GND 平面、阴极 SW 铺铜要受控）。或者接受「3V3 短路属于二次故障」，在报告里明确写出来。

**P2-4　L1 的饱和电流写的是典型值**
- `C68434` 规格书第 11 页 SWPA5040S220MT：Isat **1.60A（保证列）/ 1.90A（典型）**，Irms 1.50/1.60A，DCR 0.168Ω max。
- §5 与 BOM 写的「1.9A」是典型值。U4 的限流上限 1.7A（DS p.5）略高于 1.60A，与手册「rating near 1.6A」（DS p.12 §9.2.2.2）一致，短路时可能轻度饱和。
- 正常工作峰值只有 0.08 + 0.2/2 ≈ 0.18A，没有问题。建议文档改成保证值。

**P2-5　C40（C48971005，RV63V47M6X8）的规格书不在 `datasheets/`**
- 目录里只有旧的 `C92059_Panasonic_EEE-FT1H470AP.pdf`（50V）。
- 现在无法核对 ESR、纹波电流、浪涌电压、6.3×7.7 尺寸和焊盘。P1-1、P1-2 的 ESR 只能按 0.5Ω 估。
- 请取料方下载 `https://datasheet.lcsc.com/lcsc/C48971005.pdf` 补核。
- 封装极性已核：焊盘 1 侧有「+」丝印和倒角，符号 1 脚是「+」，接 VIN_F ✅。

**P2-6　陶瓷电容的直流偏压降额（手册里没有曲线，下面是按同类 X7R/X5R 典型值的估算，需补厂家曲线）**
- **C42**：4.7µF/100V X7R 1210，在 29–53V 下约剩 60%→40%，即 **≈2.8→1.9µF**，仍在 DS p.13 §9.2.2.5 要求的 1–10µF 内。输入纹波电流 Iout·√(D(1−D)) ≈ 0.08×0.34 ≈ 27mA，余量充足。
- **C43**：22µF/25V X5R 0805，在 3.3V 下约剩 **≥ 15µF**，在 DS p.13 推荐的 4.7–100µF 内。输出纹波 ≈ ΔI/(8·f·C) = 0.2/(8×700k×15µ) ≈ 2.4mV。
- 结论：降额后仍满足要求。

**P2-7　封装下探（规则 00 ②）**
- **C43**：0805/25V 放在 3.3V 轨上耐压过剩。可以换 0603 22µF 6.3V（如降本排查已提的 C59461，基础库），3.3V 偏置下约 8–10µF，仍 ≥ 4.7µF。
- **D7**：SMA 可以换 SOD-123FL 100V 1A，按 DS p.13 §9.2.2.4，0.5–1A 就够。但 SS210 是基础库，换成扩展库要多付上料费（¥8/种），做几片划不划算由用户定。
- **C42**：1210 对 4.7µF/100V 是必需的。换成降本排查提的 2×C13832（1µF/100V 1206，BOM 里已有）在 50V 下有效值约 1.2µF，接近 1µF 下限。**加了 P1-1 的 10Ω 之后**，高频回路只靠 C42，更要保证容量，因此不建议再缩。
- **其余不下探**：F11、L1（Isat 约束）、C40、R40/R41/C41（已是 0402）都不再缩。

**P2-8　BOM 与原理图的一致性**
- **位号不一致**：BOM 用 `C_IN_E / C_IN1 / C_OUT1 / C_BST / R_FB1 / R_FB2`，原理图是 `C40 / C42 / C43 / C41 / R40 / R41`，LCSC 编号逐一对得上（见覆盖清单）。建议 `docs/02-BOM.csv` 与 §5 改用原理图位号，否则 bomdiff 会整行对不上。
- **C381466 的制造商标错**：BOM 写 Fenghua，`datasheets/C381466_*.pdf` 实际是 **PDC 信昌（Prosperity Dielectrics）FS 系列**。料号编码 `FS32X475K101EGG` 也是 PDC 格式。这个系列是内部串联结构，手册写的是「prevent short circuit failure」，对 P1-2 的短路风险有利。
- **库里的旧编号**：封装库里 `C0402.kicad_mod` 的 `LCSC Part` 是 C1554，`R0402.kicad_mod` 是 C17168，与本页实例的 C1525、C25779/C25744 不同。导入 PCB 后，封装属性里会带一个不相干的旧编号。BOM 必须只从符号的 `LCSC` 字段导出（规则 0b）。

**P2-9　可读性（③），不含主代理已知的 VIN_F 穿 U4、文字重叠、过挤三项**
- `FB_3V3` 标签的锚点直接压在 U4.3 的引脚端点 (111.76, 53.34) 上，违反规则 ⓪c「标签不要压在引脚上」。应该引一小段线再放标签。
- U4 的 Value「LMR16006XDDCR」放在 (127.00, 60.96)，正好在 D7 位号的正右下方，读图时容易被当成 D7 的型号。U4 的位号在 (104.14, 43.18)，离本体偏远。
- F11 的 Value 只写了「1A」，建议写成「1A 63V」，额定电压是本支路的关键参数。
- 说明文字「输入 C40 47µF/63V」没有问题。加 P1-1 的电阻后要同步更新这段说明。

> **已知问题但电气上必须闭环（不计条数）**：VIN_F 导线 (55.88→132.08, y=50.80) 穿过 U4.2 GND 的端点 (111.76, 50.80)，而 GND 引线 (111.76→104.14, y=50.80) 与它**共线重叠**。当前网表是分开的（`/辅助电源/VIN_F` 与 `GND` 独立），但这种结构在 GUI 里做「清理导线」或拖动时，有可能合并成 VIN–GND 短路。返工后必须用网表确认 `VIN_F` 仍然只有 {C40.1, C42.2, F11.2（或新串阻）, U4.5}。

## 删 D6 的独立判定（补充说明要求的专项）

| 论点 | 判定 | 依据 |
|---|---|---|
| D3 在 01 页，能保护 VIN | **现在不成立**：01 页还没画，网表里没有 D3 | 复跑网表只有 10 个器件；根图 ERC 报 `isolated_pin_label BAT+` |
| 「≈53V」 | **只在 D3 电流 ≤ 56A 时成立**；设计给的 800A/1µH 工况下会超过 65V | SMDJ33A 第 2 页表 1；详细设计 §2.2 |
| 线束/走线电感引起的热插拔过冲 | 0→29.2V 阶跃在 BAT+ 上无阻尼时最多约 58V（2 倍）< 60V，会被 D3（VBR ≥ 36.7V）截掉；F11 之后有 C40 的 ESR 阻尼 | LC 阶跃响应上限 2×V |
