## 0. 结论速览（画图方先看这一节）

1. **U6 引脚分配**（详见 §1）：
   - I2C1 用默认脚 PB6/PB7，不重映射。
   - CAN1 用默认脚 PA11/PA12，不重映射。本板不用 USB，所以没有冲突。
   - BAL_CLK 用 **PA8 = TIM1_CH1**：144MHz ÷ 1920 = 75.000kHz，分频是整数，频率没有误差。
   - AFE_ALERT 接 **PB4**。选它是因为它是 5V 容忍（FT）脚，AFE 的 3V3 比 MCU 先上电时也不会往 MCU 灌电流。
   - AFE_WAKE 接 **PB5**，驱动 MP2797 的 **NSHDN**，开漏输出。
   - PRECHG_EN 接 PA1。
   - RS485 预留 PA2/PA3/PA4（USART2 + DE）。
   - LED 接 PB13/PB14/PB15，按键接 PB12。
   - SWD 用 PA13/PA14。
   - 其余 16 个脚悬空，放 NC 标志；RS485 不画时是 19 个。
2. **PWR_EN 删除**：v0.3 已取消电源自保持，LMR16006 的 SHDN 悬空即常开（docs/03 §5）。docs/03 §6 外设分配表里的 PWR_EN 需要主代理同步删掉。
3. **AFE_WAKE 就是 MP2797 的 NSHDN**：MP2797 没有叫 WAKE 的脚（MP p.5–6 引脚表）。
   - NSHDN 拉低进入关断，拉高退出关断（MP p.22）。
   - 上拉用 02 页已有的 R_WAK 10k 到 +3V3，**05 页不重复放**。
   - MCU 用开漏输出。MCU 复位时引脚高阻，NSHDN 由上拉保持为高，**AFE 不会因为 MCU 复位而关断**，FET 也不会掉。
4. **MCU 复位时各输出都进安全态**：
   - BAL_CLK：05 页加 100k 下拉（R52）。PA8 是 FT 脚，漏电流最大 3µA（CH32 p.50）；只靠 03 页的 1M 下拉，入口电平会被抬到 3V，**不够**。
   - PRECHG_EN：05 页加 100k 下拉（R51）。
   - CAN 的 TXD：05 页加 10k 上拉（R53），复位时总线保持隐性（HVD p.19）。
5. **晶振负载电容 20pF → 33pF**（C1562，基础库）：Y1 的 CL = 20pF，手册给的杂散电容是 2–7pF（CH32 p.47）。
   - 用 20pF 时有效 CL 只有 12–17pF，频率偏高约 30ppm，超出晶振 ±20ppm 的标称。
   - 用 33pF 时有效 CL 为 18.5–23.5pF，正好把 20pF 包在中间。
   - 详见 §2.4。**需要改 BOM（C_Y1/C_Y2），并且要取库。**
6. **绿灯限流电阻 1k → 330Ω**（C25104，基础库）：KT-0805G 的 VF 是 2.6–3.1V@5mA（LEDG p.2）。3.3V 串 1k 时只有 0.2–0.6mA，灯会很暗。
7. **调试口推荐 1×6 2.54mm 焊盘，默认不贴（DNP）**：顺序是 3V3 / SWDIO / SWCLK / GND / TX / RX，直接接 WCH-LinkE 的杜邦线。不贴就没有上料费，样板手焊一根排针即可。**待用户定**（U-2）。
8. **需要取库的 C 编号**（`hardware/lib/jlc/jlc.kicad_sym` 里没有）：
   - 必需：**C1562**（33pF）、**C25104**（330Ω）、**C95572**（共模电感，DNP）、**C492405**（1×6 排针封装，DNP）。
   - 视 §9 的决定而定：C8963、C32677（RS485）；C492401、C100114（终端跳线方案 B）；C2691448（1×4 排针备选）。
9. **全部新增料都是基础库或 DNP，上料费增量为 ¥0**。
   - BOM 新增 3 行基础库料：C1562、C25104、C25741。其中 C25741 已在库里，但 BOM 里的 MCU 段没有它。
   - 还有 2 行 DNP：C95572、C492405。

## 1. U6 CH32V203C8T6（C3001172，LQFP-48）逐脚分配

### 1.1 依据与原则

- **引脚号与名称**：CH32 p.21 的引脚图（CxT6 LQFP48），以及 p.23–26 的 Table 3-1-1 LQFP48 列，逐脚对过。
  库符号 `jlc:CH32V203C8T6` 的 48 个脚名、脚号也已逐条对过，与手册一致（例如 35=VSS_2、36=VDD_2、44=BOOT0）。
- **复位后状态**：
  - 除 OSC_IN/OSC_OUT 外，所有 GPIO 复位后都是**浮空输入**（CH32 p.23 Table 3-1-1「Main function (after reset)」列为 PAx/PBx，默认功能在参考手册的 GPIO 章节）。
  - PA13/PA14 复位后就是 SWDIO/SWCLK（p.25「Main function (after reset)」= SWDIO/SWCLK）。
  - PD0/PD1 复位后是 OSC_IN/OSC_OUT（p.35 Note 4）。
- **FT（5V 容忍）脚**：PB2、PB10–PB15、PA8–PA15、PB3–PB9（p.24–26 的「I/O structure」列为 FT）。
  - PA0–PA7、PB0、PB1、PC13–PC15 **不是** FT，输入电压上限 VDD+0.3V（p.38 Table 4-1）。
  - 漏电流：普通脚 1µA，FT 脚 3µA；内部弱上拉/弱下拉 30–50kΩ（p.50 Table 4-19）。
- **跨页信号**只在本页挂全局标签（04 页的风格：`+3V3`、`GND` 也用全局标签，不用电源符号）。页内网络用局部标签。

### 1.2 外设分配与选脚理由

| 功能 | 外设 / 脚 | 理由（依据） |
|---|---|---|
| AFE 通讯 | **I2C1：PB6=SCL、PB7=SDA**（默认，不重映射） | 两脚都是 FT（p.26）。MP2797 的 I2C 最高 400kHz，VIH = 0.7×AFE_3V3（MP p.16）。**上拉用 02 页的 R_I2C1/R_I2C2 2.2k 到 +3V3，本页不放**（BOM 第 28 行）。上升时间：设总线电容约 50pF，tr ≈ 0.8473 × 2.2k × 50pF ≈ 93ns，小于 400kHz 的上限 300ns ✅ |
| CAN | **CAN1：PA11=CAN_RX、PA12=CAN_TX**（默认映射） | 手册 p.25、p.36。**与 USB 的关系**：PA11/12 同时是 USBD 的 DM/DP，CAN 和 USBD 共用 512B 专用 SRAM（p.20 §2.5.18）；本板不用 USB，所以没有冲突。用默认映射，固件不需要配置 AFIO。PA11/12 的 HBM 是 3kV，其余脚 4kV（p.39），CAN 这两脚只在板内走线，外部 ESD 由 U8 承担。备选是 PB8/PB9（CAN1_*_2，重映射 10b），本版不用 |
| 均衡时钟 | **TIM1_CH1：PA8 → BAL_CLK** | ① 144MHz / 75kHz = 1920，取 PSC=0、ARR=1919、CCR1=960，得到 **75.000kHz、50% 占空比**，没有误差。② TIM1 是高级定时器，调试暂停时「计数器冻结、PWM 输出被禁止」（p.19），停机状态由 OIS1=0 定为低。③ MCU 复位后 PA8 是浮空输入，由 R52 100k 下拉保持为低，UD1 输入低，均衡停止（见 §1.4）。④ 用 IWDG 兜住 MCU 跑飞：定时器是硬件，MCU 死机时 PWM 会继续输出，**固件必须开 IWDG**（LSI 40kHz，与 LSE 无关），看门狗复位后 GPIO 回到浮空，均衡停止 |
| AFE 中断 | **PB4 ← AFE_ALERT**（EXTI4） | 选 FT 脚：AFE 的 3V3 由 MP2797 自己的 LDO 供电，最高 3.465V（MP p.13 ±5%），上电顺序也与本板的 buck 无关。如果接非 FT 脚，MCU 的 VDD 还没起来时，电流会经钳位二极管灌入。以 MP2797 GPIO 推挽上拉电阻 430Ω（MP p.14）估算，约 (3.3−0.6)/430 ≈ 6mA，**超过注入电流上限 ±5mA**（CH32 p.39）。PB4 与 PB5/PB6/PB7 同在芯片上边，四根 AFE 线可以一起走。代价是放弃 PA0 的 Standby 模式唤醒；固件待机用 STOP 模式（docs/03 §5），任何 EXTI 都能唤醒，不受影响 |
| AFE 唤醒 / 关断 | **PB5 → AFE_WAKE（= MP2797 NSHDN）**，开漏输出 | 见 §1.5 |
| 预充使能 | **PA1 → PRECHG_EN**，推挽输出，高电平有效 | 01 页的预充整块默认 DNP。本页 R51 100k 下拉保证复位时为低（Q20 NPN 不导通）。PA1 不是 FT，但只输出 3.3V，没有问题 |
| RS485 | **USART2：PA2=TX→DI、PA3=RX←RO；PA4 = DE/RE（GPIO）** | USART2 默认脚（p.23）。CH32 的 USART 没有 STM32F0 那种硬件 DE 模式，所以 DE 用 GPIO。**如果 RS485 本版不画（U-1），这三个脚放 NC，但不要分配给别的功能，留给下一版** |
| 调试 | **PA13 = SWDIO、PA14 = SWCLK** | 复位后默认就是这两个功能（p.25）。**固件不得把它们改成 GPIO**，否则只能用 BOOT0 救砖 |
| 调试串口（可选） | **PA9 = USART1_TX、PA10 = USART1_RX** → J8 的 5/6 脚 | WCH 的 ISP 引导程序也走 USART1（参考手册 Boot 章节）。只引到 J8 的 DNP 焊盘上，不贴件，零成本（U-2） |
| LED ×3 | **PB13 → LED1（红，故障）、PB14 → LED2（红，均衡中）、PB15 → LED3（绿，运行）**，灌电流接法、低电平点亮 | 复位时引脚浮空，LED 熄灭。见 §5 |
| 按键 | **PB12 ← SW1**，按下接 GND，用内部上拉 | 用户键（清故障、唤醒、查状态），**不是复位键**（U-4）。PB12 是 FT。去抖由固件做（≥20ms） |
| ~~PWR_EN~~ | **删除** | v0.3 取消了电源自保持与唤醒或门（docs/03 §5 SHDN 行、obsidian 方案笔记第 56 行）。LMR16006 SHDN 悬空即常开 |

### 1.4 每个信号的方向、复位默认态与安全态核算

| 信号 | 方向（MCU 视角） | MCU 复位 / 死机时的电平 | 核算 |
|---|---|---|---|
| BAL_CLK | 出 | **低**（R52 100k 下拉）→ 均衡停止 | PA8 是 FT 脚，漏电最大 3µA（p.50）。只靠 03 页的 RB1 1M：3µA × 1M = 3.0V，**可能被判成高电平** ✗。加 R52 后下拉为 100k∥1M = 91k，3µA × 91k = **0.27V**，低于 74LVC1G17 在 VCC≥2.3V 时的负向阈值（UD1 手册 VT− 最小值约 0.6V 量级），可判为低 ✅。正常输出时，100k 负载只多 33µA |
| PRECHG_EN | 出 | **低**（R51 100k 下拉） | PA1 漏电 1µA × 100k = 0.1V ✅。01 页 Q20 的基极网络 DNP 与否都不影响 |

### 1.5 AFE_WAKE / AFE_ALERT 的接法依据（MP2797）

- **MP2797 没有 WAKE 脚**。与主机相关的脚只有这些（MP p.5–7）：xALERT（28）、WDT（29）、NSHDN（30）、SCL（31）、SDA（32）、SDO（33）、GPIO3/nCS（34）。
  - NSHDN 是「Active-low shutdown input」（p.6）。拉低进入关断，拉高进入安全模式（p.22）。
  - 所以契约里的 **AFE_WAKE = NSHDN，高电平 = AFE 工作**。网络名保持不变，含义与电平方向一致。
  - NSHDN 的绝对最大值是 9V（p.7），3.3V 驱动没有问题。
  - **7.6V 是 MTP 编程电压**（VNSHDN_PROG，p.14），本板不产生这个电压，没有风险。
- **WDT（29 脚）不接 MCU**：它在咬狗事件时输出 10ms 的**高**脉冲（p.14、p.24），而 CH32 的 NRST 是低有效，直接接会反相。
  - 按 MP Table 23（p.127）的「Float this pin if it is not used」悬空（由 02 页处理）。
  - 所以 docs/03 §3.1「WDT 开漏上拉 10kΩ」一句需要 02 页复核：WDT 不用就不上拉。
- **xALERT 是推挽输出，不是开漏**：手册写「configured to be an active high **(3.3V)** or active low」（p.24）。**OTP 默认 ALERT_POL = 1，即高有效**（p.48 PINS_CFG 0x0D Bit[0]，Reset 0x1）。
  - 02 页 BOM 的 R_ALT 是「开漏上拉 10k」。在默认的高有效模式下，空闲时引脚被 AFE 拉低，10k 上拉就会**持续消耗 0.33mA**，这对待机目标 < 300µA 是明显的负担。
  - 交 02 页定夺，见 X-2。
  - **本页不管 02 页怎么选，都只做直连 + MCU 内部下拉。**

### 2.1 电源脚逐一点名去耦（CH32 Fig 4-1 p.38、Fig 4-13 p.56）

- **C55 容量核算**：
  - 4.7µF/16V X5R 0603 在 3.3V 偏置下约剩 3.5µF。
  - 最大负载阶跃按 CAN 显性 ≈ 2V/60Ω ≈ 33mA、持续 2µs 计：ΔV = I·t/C = 33mA × 2µs / 3.5µF ≈ **19mV** ✅。

### 2.2 NRST（CH32 Fig 4-7 p.51、Table 4-22 p.50）

- 手册电路是：NRST 接 0.1µF 到地，另有一只可选按键到地，芯片内部上拉 RPU 30–50kΩ。
- 本设计：**C58 100nF 0402（C1525）接 NRST–GND，不加外部上拉，不接按键**（U-4）。
- 核算：
  - τ = 40k × 100nF = 4ms。
  - 芯片内部上电复位延时 tRSTTEMPO = 24–30ms（p.40），比 τ 长得多，RC 只起滤波作用。
  - 滤波脉宽 100ns 以内的毛刺被滤掉（p.51 VF(NRST)）。
- NRST 不引到 J8：CH32V203 的 2 线调试不需要 NRST。WCH-LinkE 靠 SWD 命令复位。

### 2.3 BOOT0

R50 10k 0402（C25744）接 BOOT0–GND，从用户 Flash 启动。PB2/BOOT1 悬空（BOOT0 = 0 时 BOOT1 不起作用）。依据：p.35 Note 5/6。

### 2.4 HSE 12MHz：Y1 C9002 与负载电容核算

**晶振参数**（XTAL；嘉立创接口也返回「12MHz 20pF 80Ω ±10ppm ±20ppm」）：

| 参数 | 值 |
|---|---|
| CL | 20pF |
| 12MHz 档 ESR 最大 | 80Ω |
| C0 最大 | 3pF |
| 激励功率 | 10–200µW |
| 脚位 | **1、3 = 晶体两端，2、4 = GND**（库符号：1 OSC1 / 2 GND / 3 OSC2 / 4 GND） |

**负载电容公式**（CH32 p.47）：CL = CL1·CL2/(CL1+CL2) + Cstray，Cstray 典型值 **2–7pF**。取 CL1 = CL2 = C：

- C = 2 × (CL − Cstray) = 2 × (20 − 2…7) = **26–36pF**，取中值约 31pF。

| 选项 | 有效 CL（Cstray 2–7pF） | 结论 |
|---|---|---|
| BOM 现值 **20pF C1554** | 10 + 2…7 = **12–17pF** | 偏小 3–8pF。频偏 Δf/f ≈ (C1/2)·[1/(C0+CL′) − 1/(C0+CL)]，C1 取 12MHz 3225 典型值约 5fF、C0 = 3pF、CL′ = 14.5pF：Δf/f = 2.5fF × (1/17.5 − 1/23)pF⁻¹ ≈ **+34ppm**，超出晶振 ±20ppm 的标称（对 CAN 500k 的 0.1% 级容差仍够用）|
| **推荐 33pF C1562**（0402 C0G，**基础库**，库存 1 103 358，$0.0039） | 16.5 + 2…7 = **18.5–23.5pF** | 20pF 落在区间中间 ✅，不增加上料费 |
| 30pF C1570 | 17–22pF | 扩展库，不选 |
| 27pF C1557 | 15.5–20.5pF | 扩展库，不选 |

**起振裕量**：
- 临界跨导 gm_crit = 4·ESR·(2πf)²·(C0+CL)² = 4 × 80 × (2π × 12MHz)² × (23pF)² ≈ **0.96mA/V**。
- 手册给的 gm = 17.5mA/V（p.46 Table 4-11），裕量 **18 倍**（要求 ≥ 5）✅。

**激励功率**：
- 手册给的 HSE 驱动电流是 0.53mA @20pF（p.46）。
- P = ESR·I² = 80 × (0.53mA)² ≈ **22µW**，小于晶振上限 200µW ✅。
- 不需要串联限流电阻 Rext。

**PLL**：HSE 12MHz × 12 = 144MHz。PLL 输入范围 3–25MHz（p.48 Table 4-15），12MHz 在范围内 ✅。固件 HSE_VALUE = 12MHz（BOM 第 67 行备注）。

**⚠ 这一条需要改 BOM**：C_Y1/C_Y2 由 C1554 20pF 改为 **C1562 33pF**。按规则 0b，先改原理图再改 BOM，由主代理报用户确认（见 U-6）。

### 2.5 LSE：不需要

- RTC 不要求走时（时间戳由上位机给）。IWDG 用内部 LSI 40kHz（p.47），不依赖 LSE。
- PC14/PC15 放 NC。
- 如果日后需要 RTC 计时，另加 32.768kHz 晶振 + 2×12pF（p.47 推荐约 12pF）。本版不做。

| 负载 | 电流 |
