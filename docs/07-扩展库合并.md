# 07 扩展库合并排查（parts 角色，2026-09-26 15:18）

> 只给提案和数据，**没有改** `docs/02-BOM.csv`、设计文档和库文件。
> 口径与 `06-降本排查.md` 相同：嘉立创 SMT 接口实时美元阶梯价 × 7.1，按「单板用量 × 板数」取价格档；
> 扩展库上料费按每种每单 ¥8 计（10 块档折合 ¥0.80/块，100 块档折合 ¥0.08/块）；库存指**嘉立创 SMT 库存**。

## 0. 先说结论

1. **嘉立创基础库现在只剩 351 种料。** 我用 `componentLibraryType:"base"` 把整个基础库翻完了，全表存在 scratchpad 的 `base.json`。
   里面**没有**稳压管、100V 的 10nF/470nF/1µF 电容、保险丝、NTC、功率电感、铝电解、单门施密特、CAN ESD，也没有 3kW 的 33V TVS。
   基础库里 ≥100V 的 MLCC 只有 C28233（100nF/100V 0805，BOM 已在用）和 C9196（1nF/2kV）两种。
2. **能换成基础库的只有 QN 和 QP，但换了都不划算。** QN 可换 AO3400A C20917，QP 可换 AO3401A C15127。
   可是这两颗基础库料的单价比现在的扩展库料还贵，差价超过省下的上料费；QP 换 AO3401A 还会让均衡电流少 17%。结论是**不推荐**。
   **在「只算基础库」这个口径下，没有一项能在不降裕量、不涨成本的前提下减少扩展库种类。**
3. **BOM 内部也没有能合并的料号：**
   - DZ1/DZ2 是 15–16V，D_C0 是 3.3V，电压不同，不能统一。
   - C_VTOP 手册写的是 470nF「Required」，C_PACK 手册写的是 10nF「Do not use a capacitor larger or smaller」（MP2797 Table 18，第 123 页），
     所以都不能并到 BOM 里已有的 1µF/100V（C282823）或 100nF/100V（C28233）上。
   - F11 不能并入 F2–F10，原因见表 1。
4. **另一条路是「优选扩展库」（Preferred Extended，1235 种）。** JLCPCB 官方 FAQ 的原话：*"exempt from the Feeders Loading fee for **Economic** PCB assembly"*。
   也就是说，只有经济型贴片才免上料费；标准型贴片免不免，页面没说。
   **如果这块板实际走的订单类型确实能免**，下面 3 种可以推荐：DZ1/DZ2 → BZT52C16S，D_C0 → BZT52C3V3（优选），U8 → H24VNT2B。
   三种都是同封装、同脚位、规格不降，扩展库减 3 种，10 块档每块省约 ¥2.20，100 块档每块省约 ¥0.13。
   **这一条要由用户在下单页核实（见 §3 存疑 1），核实之前不要改。**

- 方案 A 是在花钱减种类，而且 QP 那一步还会让均衡电流少 17%。**不推荐。**
- 方案 B 的收益几乎全来自免上料费。如果订单类型不免费（例如标准型贴片照收），这 3 项的净变化是 10 块档每块 +¥0.20、100 块档每块 +¥0.11，那就**不要换**。
- 单价是 2026-09-26 15:10 左右从接口实时取的，汇率按 7.1。

## 3. 存疑（交用户定夺）

1. **优选扩展库在本项目的订单类型里免不免上料费？** JLCPCB 官方 FAQ 只说经济型贴片免。
   本板有 TOLL MOSFET、3 个直插连接器、SMC TVS，可能只能走标准型贴片。还有一点要注意：国内嘉立创下单页的计费规则可能和海外站不同。
   **建议在下单页把 C19077449 加进 BOM，看它显示的上料费是 0 还是 ¥8，再决定是否采纳方案 B。**
2. 规则 0e 要求封装从嘉立创取。方案 B 的 3 颗料封装名都相同（SOD-323 / SOD-123 / SOT-23），但**采纳前**仍要用新 C 编号跑一遍 `easyeda2kicad` 取库，
   再用 `fp_compare.py` 和原封装逐个焊盘比对；U8 还要核对符号的引脚号对应关系（1、2 脚接线，3 脚公共端）。
   本次没有取库：取库要求放行 easyeda.com，而且另一个会话正在同一分支上改图，不能动库文件。
3. DZ1/DZ2 从 15V 改成 16V 是向手册推荐值靠拢（Table 18 写的是 16V）。如果设计方有意选 15V 留裕量，就用 C19077448（15V 优选）。
4. **库存风险**：D1–D3 C2976503 的库存 725 只够 241 块，J5 C40669 的库存 244 只够 244 块。量产前要备货或另选料。
   QP 的 AO3415A 库存 5293，100 块的用量够，但库存偏少。
5. 本次按标准型上料费 ¥8/种计算。`tools/cost.py` 注释写的是「经济型 ¥20」，这与 JLCPCB FAQ「经济型免优选扩展库上料费、普通扩展库 $3/种」的说法对不上，两个站点的计费规则需要用户核实。
