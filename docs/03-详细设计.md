## 2. 功率回路（01_power_path）

### 2.1 拓扑：高边、背靠背、**共源**

```
BAT+ ─F1─┬─ D[Q1..Q8 DSG]S ─┬─ FET_MID ─┬─ S[Q9..Q16 CHG]D ─┬─ PACK+
         │                  │           │                   │
      TVS D3            Gate DSG_G   Gate CHG_G        TVS D1,D2 + C 10×1µF
BAT- ─────────── RS1 100µΩ ────────────────────────────────── PACK-
       (GND 单点)   ↑SRN     ↑SRP
```

- **DSG 管放电池侧**：DSG 管关断时，它的体二极管方向是 FET_MID→BAT+，只能充电不能放电；
  CHG 管同理，只能放电不能充电。
- 两组源极接在一起（FET_MID），两组栅极都以 FET_MID 为参考，由 MP2797 的高边电荷泵驱动。
  **MP2797 要求共源还是共漏、驱动参考脚接哪里，都以手册为准【待核】**，本拓扑不对就改成共漏。
- 对 v0.1 的修正：v0.1 写的是"CHG 组 → DSG 组"，现改为按体二极管方向明确定义的顺序。

### 2.2 器件与取值（逐件算最坏工况耗散）

| 位号 | 器件 | 取值/型号 | 所在支路 | 最坏工况 | 耗散 / 裕量 |
|---|---|---|---|---|---|
| F1 | 熔断器 | 300A ANL/MEGA | 串联于 BAT+ | 200A 持续 | 选型 ≥1.5×，自身压降按手册 |
| Q1–Q16 | N-MOSFET | Infineon IPT012N08N5，**C531199**，80V/300A/≤1.2mΩ，Qg≈178nC，TOLL【SOA 待核】 | 每组 8 并联，两组串联 | 200A、Tj 热态、均流偏差 15% | 单管 1.69W，Tj≈79°C（Rθja 20K/W）|
| RG1–16 | 栅极串阻 | 10Ω 0402 | 与各管栅极串联 | 开关瞬态 | 平均功耗 ≪ 1mW |
| RGS1–16 | G-S 下拉 | 100kΩ 0402 | 并联于每管 G-S | Vgs=12V 常通 | 1.44mW / 额定 62.5mW |
| DZ1, DZ2 | 栅极钳位稳压管 | MM3Z15，**C65676**，15V SOD-323（每组 1 只，并在栅极母线与 FET_MID 之间） | 并联 | 驱动过冲时 | 驱动能力 mA 级，功耗 <50mW |
| Q17, Q18 | PNP 快速关断 | Nexperia PBSS5140T，**C89581**，40V/1A，SOT-23 | E 接栅极母线，C 接 FET_MID | 关断时释放 1.42µC | 单次脉冲，平均 ≈0 |
| D4, D5 | 驱动隔离二极管 | BAT54WS，**C22629**，SOD-323 | 串在驱动输出与栅极母线之间 | 导通时 | 电荷泵电流 µA–mA 级 |
| RB1, RB2 | PNP 基极电阻 | 1kΩ 0402 | 驱动输出 → PNP 基极 | — | ≪ 1mW |
| RS1 | 分流器 | Vishay WSLP5931L1000FEA，**C2091034**，100µΩ ±1%，15W，5931 封装（2 端子） | 串联于 BAT-→PACK- | 200A | 4W / 15W；**TCR ±300ppm**，用 NTC_SHUNT 做固件温度补偿；2 端子，靠焊盘切分做开尔文取样 |
| D1, D2 | TVS | SMDJ33A ×2，**C438163**（PACK+→PACK-） | 并联 | 关断尖峰 | VC≈53V < 80V×0.8=64V ✅ |
| D3 | TVS | SMDJ33A ×1（BAT+→BAT-） | 并联 | 电池侧线束电感能量 | 800A 下 ½LI²（L=1µH）=0.32J |
| C1–C10 | MLCC | 1µF/100V X7R 1206，**C13832** | PACK+→PACK- | 29.2V | 100V 在 29V 偏置下有效容量约 60% |
| C11–C14 | MLCC | 1µF/100V X7R 1206 | BAT+→BAT- | 同上 | — |

**快速关断原理**：驱动输出为高时，经 D4 给栅极母线充电，PNP 的 BE 结反偏、截止。
驱动输出拉低时，栅极母线电压高于基极，PNP 导通，直接把 8 颗管的栅极电荷泄放到 FET_MID。
两组各一套（充电方向短路同样需要快关）。

### 2.3 预充电路（可选，默认 DNP）

MP2797 的 DSG 软启动能限制浪涌，负载电容不大时不需要预充。若负载电容 > 10mF（如逆变器），就贴上：

| 位号 | 器件 | 取值 | 计算 |
|---|---|---|---|
| Q19 | P-MOSFET（BAT+ → 预充电阻） | Vishay SQ2361ES，**C727403**，-60V/-2.8A，177mΩ，SOT-23 | 峰值 0.97A：导通损耗 0.97²×0.177 = 0.17W，仅持续约 1s |
| Q20 | NPN / 小信号 NMOS | 电平转换，由 MCU PRECHG_EN 驱动 | — |
| RP1, RP2 | 预充电阻 | 2 × 15Ω 5W（**C334293**，是否绕线、能否承受 4.26J 脉冲【待核】；串联 = 30Ω） | 峰值 0.97A、28W；单次能量 ½CV² = **4.26J**（10mF）；t95 = 0.9s |
| DZ3 + R | PMOS 栅极钳位 | 12V 稳压管 + 10k/10k 分压 | Vgs 不超过 ±20V |

**软件保护**：预充超过 1.5s 仍 PACK+ < 90%×BAT+，判定为负载短路，立即关闭 Q19。
否则 RP 会持续承受 28W 并烧毁。电阻上消耗的能量恒等于 ½CV²，与阻值无关，所以只能靠限时保护。

### 2.4 端子与线束

| 位号 | 用途 | 型号建议 | 依据 |
|---|---|---|---|
| J1–J4 | BAT+ BAT- PACK+ PACK- | M8 螺柱 + 20×2mm 紫铜排 | 200A 下电流密度 5A/mm²；150mm 长、80°C 时 79.7µΩ、3.2W |
| J5 | 采样 CELL0..8 + NTC_CELL1/2 | JST B13B-XH-A，**C158025**，2.50mm 13P 板端顶插座（**不是 2.54mm 的 2501 系列**） | 规则 0b 取库教训 |
| J6 | 均衡 BAL0..8 | Molex Micro-Fit 3.0 2×5 立式板端座 **43045-1012，C277725**（v0.1 写的 43045-1000 是弯针座，已更正） | 均衡峰值 3.75A |

- **采样线与均衡线分开进板、分开连到电芯极柱**，否则 3A 均衡电流会在采样线上产生几十 mV 误差。
- **每根均衡线串 5A 保险丝（1206，F2–F10，SART S1206-SD-5.0A，C553937，63V；是否快熔【待核】）**。线束磨破短路时，单节电芯能提供上千安电流，
  没有保险丝就会起火。
- 采样线的电流很小，靠 AFE 输入端的串联电阻限流即可（见 3.2）。

## 3. AFE：MP2797（02_afe）

### 3.1 需要按手册 Typical Application 逐件点名核对的外围件【全部待核】

| 功能 | 外围件（按功能列，引脚号待手册） |
|---|---|
| 供电 | VDD/BAT 输入 RC 滤波（典型 100Ω + 1µF/100V）；内部 LDO 输出电容（按手册值）|
| 电芯采样 VC0..VC8 | 每路串联 R + 对地/相邻 C；**8 串使用 16 通道器件时，未用通道按手册要求短接或悬空** |
| 电流采样 SRP/SRN | 2×100Ω + 0.1µF 差模 + 2×10nF 共模 |
| 高边驱动 | 电荷泵飞电容/储能电容（若外置）、CHG/DSG 输出、驱动参考脚接 FET_MID |
| PACK 检测 | PACK+ 分压/限流电阻（负载/充电器检测、软启动） |
| NTC ×4 | 上拉到内部基准；每路并 0.1µF |
| 通讯 | I2C 上拉 2.2kΩ 到 +3V3（或 SPI）；开启 CRC |
| ALERT / WAKE | 开漏上拉 10kΩ；WAKE 同时进入辅助电源的唤醒 OR 门 |
| 被动均衡 | 内部 MOSFET，58mA 最大；电流路径是否流经 VC 串联电阻【待核】 |

### 3.2 电芯采样 RC 的取值（取决于被动均衡电流走哪条路）

- **情况 A：被动均衡电流不经过 VC 串阻**。取 R = 100Ω（0402），C = 0.1µF。
  转折频率 15.9kHz，每路电阻功耗 ≈ 0。
- **情况 B：被动均衡电流流经 VC 串阻**（多数 AFE 属于这种）。要满足 3.65V ÷ (2R + Ron) ≈ 58mA，
  可得 R ≈ 30Ω。此时 **P = 0.058² × 30 = 0.10W，0402（62.5mW）不够**，按规则 00 ② 逐档往上：
  0603（100mW）余量为 0，也不行；**最终用 0805（125mW）**。
- 在手册确认之前，按情况 B 留 0805 焊盘。

### 3.3 NTC（Murata NCP18XH103F03RB，**C13564**，10kΩ，0603，上拉 10kΩ）

立创标注 B 值为 **B25/50 = 3380K**，v0.1 写的“B3435”其实是这颗料的 B25/85。下表按 B25/50 = 3380K 计算，
适用于 0~50°C。高温段（65°C、100°C）的保护阈值和固件查表，**直接用 Murata 的 R-T 表**，不要用单一 B 值外推。

| 温度 °C | -20 | 0 | 25 | 45 | 55 | 65 | 100 |
|---|---|---|---|---|---|---|---|
| V_NTC / V_REF | 0.882 | 0.738 | 0.500 | 0.329 | 0.262 | 0.207 | 0.093 |

保护阈值（0°C、55°C、65°C、100°C）对应的比值相互间隔都 ≥ 0.05，ADC 分辨率足够区分。
上拉电阻用 0.1% 精度、0402。

## 5. 辅助电源（04_power_supply）

```
BAT+ ─F11 1A─┬─ D6 SMBJ33A ─┐
             ├─ C 47µF/50V 电解 + 2×4.7µF/100V X7R 1210（规则 00 ①：工业输入必须带电解）
             └─ MP9486A ── L ── +5V (≤300mA) ── LDO ── +3V3
                  EN ← 唤醒 OR 门 {AFE_WAKE, PWR_EN(MCU 自保持), 按键}
```

| 检查项（规则 00 ①a 拓扑完备性） | 设计 |
|---|---|
| MP9486A（MP9486AGN-Z，**C404013**，SOIC-8-EP）是**非同步 buck**（只集成上管，手册原文要求 "A low forward voltage Schottky rectifier to ground is required"，来自搜索摘要） | **必须加 SW→GND 续流肖特基 D7：SS310，C15874，100V/3A SMA**，这是最容易漏的一颗 |
| 控制方式 | 迟滞控制，频率随工况变化，最高 1MHz；输出全用 MLCC 时 FB 纹波可能不足，需按手册加前馈电容或纹波注入【待核】 |
| 自举电容 CB（SW→BST） | 按手册，典型 0.1µF/0402 |
| 电感 | 按手册公式与开关频率算纹波（频率待核）；下方禁铜 |
| 反馈分压 | FB 调节点约 0.2V（来自搜索摘要，**待手册核实**），5V 对应约 1:24，**不能照抄常见的 0.8V 方案**；0402 1% |
| 输入电容降额 | 4.7µF/100V 1210 在 29V 偏置下剩约 60% |
| LDO | MP2013AGQ-33-Z，**C6096988**，QFN-8(3x3)，2.5–40V 输入，150mA，Iq 3.3µA；输入/输出电容按手册 |

**功耗预算（+5V）**：MCU 约 20mA，CAN 显性位约 70mA，AFE 数字 IO 与 LED 约 10mA，合计 ≤ 100mA，
MP9486A 的 1A 能力余量充足。

**休眠**：MCU 拉低 PWR_EN → buck 关断 → 只剩 AFE 低功耗采样。
休眠电流目标 < 300µA，需在手册核对 MP2797 休眠电流后校核。

| BAL_3A | 1.2 | 0.3 | 0.8/0.4 | BAL* |

| GATE | 0.4 | 0.3 | 0.6/0.3 | CHG_G DSG_G |

  所有过孔都 ≥ 0.3/0.45mm，满足嘉立创四层板下限（规则 2b）；板框铜间距 0.3mm。
- **差分对（规则 0c，布局前定）**：CAN_H/L 120Ω、RS485_A/B 120Ω，按嘉立创实际叠层用阻抗计算器重算线宽线距；
  顺序为连接器 → ESD → 收发器，走顶层直通道。SRP/SRN 不是阻抗线，但要紧耦合成对走，远离 MOSFET。
- **禁铜区（规则 2d）**：MP2645A 的功率电感、MP9486A 电感，所有铜层都禁铜。
- **收尾**：泪滴（规则 2c）→ DRC=0 → Gerber 自检（规则 2b）。

## 10. 立创选料结论

完整料表见 `docs/04-立创选料.md`（29 项，全部来自立创/LCSC 的搜索结果，没有打开过商品页）。对设计的主要影响：

- **MP2645A 立创和 LCSC 都搜不到**（2026-07 才发布，pre-release，QFN-19 4×4）。BOM 里标为客供料，贴片时走自备料；也可以第一版先不贴（DNP）。**这是最大的供货风险。**
- 分流器：立创上没有同时满足 0.1mΩ、≥10W、4 端子、锰铜的料，本版选 WSLP5931（15W、2 端子），并用 NTC_SHUNT 做温漂补偿。精度不够的话，就从立创以外的渠道买 4 端子锰铜分流器，这需要你来决定。
- **所有项的嘉立创 SMT 库存和基础库/扩展库属性都没查到**，需要你在嘉立创核实（规则 0b 换料四项里的价格和可采购性）。
