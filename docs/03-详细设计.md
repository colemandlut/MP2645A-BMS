## 2. 功率回路（01_power_path）

### 2.1 拓扑：高边、背靠背、**共源**

```
BAT+ ─F1─┬─ D[Q1..Q6 DSG]S ─┬─ FET_MID ─┬─ S[Q7..Q12 CHG]D ─┬─ PACK+
         │                  │           │                   │
      TVS D3            Gate DSG_G   Gate CHG_G        TVS D1,D2 + C 10×1µF
BAT- ─────────── RS1 100µΩ ────────────────────────────────── PACK-
       (GND 单点)   ↑SRN     ↑SRP
```

- **DSG 管放电池侧**：DSG 管关断时，它的体二极管方向是 FET_MID→BAT+，只能充电不能放电；
  CHG 管同理，只能放电不能充电。
- 两组源极接在一起（FET_MID），两组栅极都以 FET_MID 为参考，由 MP2797 的高边电荷泵驱动。
  **MP2797 要求共源还是共漏、驱动参考脚接哪里，都以手册为准【待核】**，本拓扑不对就改成共漏。
- 对 v0.1 的修正：v0.1 写的是"CHG 组 → DSG 组"，现改为按体二极管方向明确定义的顺序。

两组各一套（充电方向短路同样需要快关）。

### 2.3 预充电路（可选，默认 DNP）

MP2797 的 DSG 软启动能限制浪涌，负载电容不大时不需要预充。若负载电容 > 10mF（如逆变器），就贴上：

| 位号 | 器件 | 取值 | 计算 |
|---|---|---|---|
| Q19 | P-MOSFET（BAT+ → 预充电阻） | Vishay SQ2361ES，**C727403**，-60V/-2.8A，177mΩ，SOT-23 | 峰值 0.97A：导通损耗 0.97²×0.177 = 0.17W，仅持续约 1s |
| Q20 | NPN / 小信号 NMOS | 电平转换，由 MCU PRECHG_EN 驱动 | — |
| RP1, RP2 | 预充电阻 | 2 × 15Ω 5W（**C334293**，是否绕线、能否承受 4.26J 脉冲【待核】；串联 = 30Ω） | 峰值 0.97A、28W；单次能量 ½CV² = **4.26J**（10mF）；t95 = 0.9s |
| DZ3 + R | PMOS 栅极钳位 | 12V 稳压管 + 10k/10k 分压 | Vgs 不超过 ±20V |

**软件保护**：预充超过 1.5s 仍 PACK+ < 90%×BAT+，判定为负载短路，立即关闭 Q19。
否则 RP 会持续承受 28W 并烧毁。电阻上消耗的能量恒等于 ½CV²，与阻值无关，所以只能靠限时保护。

  没有保险丝就会起火。
- 采样线的电流很小，靠 AFE 输入端的串联电阻限流即可（见 3.2）。

### 3.2 电芯采样 RC 的取值（取决于被动均衡电流走哪条路）

- **情况 A：被动均衡电流不经过 VC 串阻**。取 R = 100Ω（0402），C = 0.1µF。
  转折频率 15.9kHz，每路电阻功耗 ≈ 0。
- **情况 B：被动均衡电流流经 VC 串阻**（多数 AFE 属于这种）。要满足 3.65V ÷ (2R + Ron) ≈ 58mA，
  可得 R ≈ 30Ω。此时 **P = 0.058² × 30 = 0.10W，0402（62.5mW）不够**，按规则 00 ② 逐档往上：
  0603（100mW）余量为 0，也不行；**最终用 0805（125mW）**。
- 在手册确认之前，按情况 B 留 0805 焊盘。

### 3.3 NTC（Murata NCP18XH103F03RB，**C13564**，10kΩ，0603，上拉 10kΩ）

立创标注 B 值为 **B25/50 = 3380K**，v0.1 写的“B3435”其实是这颗料的 B25/85。下表按 B25/50 = 3380K 计算，
适用于 0~50°C。高温段（65°C、100°C）的保护阈值和固件查表，**直接用 Murata 的 R-T 表**，不要用单一 B 值外推。

| 温度 °C | -20 | 0 | 25 | 45 | 55 | 65 | 100 |
|---|---|---|---|---|---|---|---|
| V_NTC / V_REF | 0.882 | 0.738 | 0.500 | 0.329 | 0.262 | 0.207 | 0.093 |

保护阈值（0°C、55°C、65°C、100°C）对应的比值相互间隔都 ≥ 0.05，ADC 分辨率足够区分。
上拉电阻用 0.1% 精度、0402。

## 4. 主动均衡：MP2643 ×7（03_balancer）

依据：`datasheets/MP2643GR_MPS.pdf`（MP2643 Rev 1.1，2025-11-14）。

### 4.1 拓扑

MP2643 是**两节相邻电芯**之间的双向均衡器：buck 模式把上节（CU）的电荷搬到下节（CL），boost 模式反过来（手册 p12）。
8 串用 **7 颗**，第 k 颗（U_BALk，k=1..7）接：

| 引脚 | 接到 | 说明 |
|---|---|---|
| PGND / AGND / 散热焊盘 | BAL(k−1) | 下节负极 = 该芯片的本地地，**7 颗各在一个电位上** |
| CL | BALk | 下节正极（2.4–4.5V） |
| CU | BAL(k+1) | 两节串联的正极（3.9–16V） |

所以任意两节之间的电荷都能沿相邻对一级级传递（手册 p1「Interleavable」）。

这些是芯片层兜底，BMS 的主保护仍是 MP2797 + MCU。

### 4.3 跨电位控制：每颗 2 个光耦，全部由 MCU 驱动

EN、MODE 的逻辑门限是 VIL 0.4V / VIH 1.0V，**以各自的 AGND（下节负极）为参考**（手册 p7），
MCU 在 GND 电位，必须隔离或电平移位。

- **方案**：每颗芯片用 2 只光耦 EL3H7(C)（**C92243**，SSOP-4，CTR 130–260%，嘉立创库存约 9.7 万），共 **14 只**。
  - 输入侧：MCU GPIO（推挽，高有效）→ 1kΩ → LED → GND，IF ≈ (3.3−1.2)/1k = 2.1mA；14 路全开共 29mA。
  - 输出侧：光敏管集电极接本芯片 **CL**（下节正极，2.5–3.65V），发射极接 EN（或 MODE），100kΩ 下拉到本芯片 AGND。
    导通时 EN ≈ VCL − Vce(sat) ≥ 2.3V > VIH 1.0V；关断时暗电流 nA 级，EN ≈ 0。
    EN 绝对最大 5.5V，而 CL ≤ 3.65V（LFP），不会超压。
  - 每只导通时从下节取 V/100k ≈ 35µA，可忽略；全关时只剩暗电流，**不会造成电芯间的不均衡漏电**。
- **失效安全**：MCU 复位或掉电 → GPIO 高阻 → LED 灭 → EN = 0 → 均衡全部停止（EN 内部默认为低，手册 p5）。
- **为什么不照搬手册 Figure 7**：原厂参考用 AFE 的被动均衡开关驱动 EN、只给 MODE 用光耦（7 只）。
  本设计还要用 MP2797 的被动均衡做 mV 级微调，两者会互相牵连，所以 EN 也用光耦，由 MCU 独立控制。

| 均衡端子 | 2×9 Micro-Fit，每节点 2 针（17A 额定），**7A 保险丝** | 2.4 节 |
| 均衡区温度 | 新增 NTC_BAL（10k，C13564）贴在均衡区，接 MCU ADC；> 70°C 降为同时最多 2 颗，> 85°C 全停【固件待加】 | — |

**均衡速度**：200Ah 电芯、5% SOC 偏差（10Ah），单对 1.78A × 0.89 ≈ **6.3 h**；
若偏差分散在多节、4 颗并行，时间相应缩短。偏差要跨多节传递时（例如第 8 节高、第 1 节低），电荷逐级转移，比单对更慢。

### 4.5 布局要点（手册 p19 + 规则 2d）

- 每颗芯片的 CCU、CCL、PGND 铜皮紧贴芯片，功率回路最短；SW 节点短、远离光耦信号线。
- **7 颗芯片各有独立的本地地（BAL0..BAL6）**，不能接到板级 GND，也不能互相连通；每颗一块铜岛，内层按电位分割。
- 电感下方**所有铜层禁铜、禁布线**（规则 2d）；7 颗电感都要画 Rule Area。
- 光耦跨隔离带放置，一次侧（MCU 侧）与二次侧（电芯侧）之间留 ≥ 1mm 爬电距离（电压只有 29V，按工艺即可）。
- 4 层板是手册推荐（p19），与本项目叠层一致。

### 4.6 固件均衡策略（已实现：`firmware/src/bms_logic.c`，单元测试 190/190）

1. **整组起停**：沿用顶部均衡（最高节 ≥ 3.40V 且压差 ≥ 30mV）与静置均衡（静置 30min、压差 ≥ 80mV）；压差 ≤ 10mV 结束。
2. **逐对方向**：对每条边界 k（cell k 与 cell k+1 之间），计算边界以上各节相对均值的电压超出之和 E_k（要拉平整组、必须穿过这条边界的电荷量）。
   E_k > 0 → U_BAL(k+1) **buck**（MODE=0，上→下）；E_k < 0 → **boost**（MODE=1，下→上）。启动门限 8mV·节、停止 3mV·节（迟滞）。
3. **交错**：相邻两颗不同时开；已在运行的对优先保留，其余按 |E_k| 从大到小加入。
4. **收尾**：全部边界都低于门限、但整组压差仍 > 10mV 时，只开需求最大的一对继续，直到所有边界 < 1mV·节。
5. **被动微调**：主动均衡结束后，由 MP2797 内部 58mA 被动均衡处理最后几 mV。
6. 仿真：初始压差 90mV 的 8 节电芯，简化电荷模型 44 步收敛到 10mV，过程中从未出现相邻两颗同时开启。

## 10. 立创选料结论

完整料表见 `docs/04-立创选料.md`（29 项，全部来自立创/LCSC 的搜索结果，没有打开过商品页）。对设计的主要影响：

- **均衡器改用 MP2643**（v0.3）：MP2645A 与 MP2643 在嘉立创都只有客供占位料号（库存 0）。MP2643 从 MPS 官网购买（MP2643GR-Z：1 片 ¥19.28、10 片 ¥17.25、100 片 ¥14.46，库存 3639，用户 2026-09-26 截图），寄嘉立创按客供料贴片。它的封装在 EasyEDA 库里没有，改用用户提供的 **MPS 原厂 KiCad 库**（`hardware/lib/mps/`），已逐焊盘核对手册 p22 推荐焊盘图、逐脚核对引脚定义（规则 0e 的「非嘉立创件」）。
- 分流器：立创上没有同时满足 0.1mΩ、≥10W、4 端子、锰铜的料，本版选 WSLP5931（15W、2 端子），并用 NTC_SHUNT 做温漂补偿。精度不够的话，就从立创以外的渠道买 4 端子锰铜分流器，这需要你来决定。
- 嘉立创库存、基础库/扩展库、单价：已可用 `python3 tools/jlc_api.py <C编号>` 直接查询（嘉立创 SMT 料号接口），成本见 `docs/05-成本估算.md`。
