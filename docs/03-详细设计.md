## 2. 功率回路（01_power_path）

### 2.1 拓扑：高边、背靠背、**共源**

```
BAT+ ─F1─┬─ D[Q1..Q6 DSG]S ─┬─ FET_MID ─┬─ S[Q7..Q12 CHG]D ─┬─ PACK+
         │                  │           │                   │
      TVS D3            Gate DSG_G   Gate CHG_G        TVS D1,D2 + C 10×1µF
BAT- ─────────── RS1 100µΩ ────────────────────────────────── PACK-
       (GND 单点)   ↑SRN     ↑SRP
```

- **DSG 管放电池侧**：DSG 管关断时，它的体二极管方向是 FET_MID→BAT+，只能充电不能放电；
  CHG 管同理，只能放电不能充电。
- 两组源极接在一起（FET_MID），两组栅极都以 FET_MID 为参考，由 MP2797 的高边电荷泵驱动。
  **MP2797 要求共源还是共漏、驱动参考脚接哪里，都以手册为准【待核】**，本拓扑不对就改成共漏。
- 对 v0.1 的修正：v0.1 写的是"CHG 组 → DSG 组"，现改为按体二极管方向明确定义的顺序。

### 3.2 电芯采样 RC 的取值（取决于被动均衡电流走哪条路）

- **情况 A：被动均衡电流不经过 VC 串阻**。取 R = 100Ω（0402），C = 0.1µF。
  转折频率 15.9kHz，每路电阻功耗 ≈ 0。
- **情况 B：被动均衡电流流经 VC 串阻**（多数 AFE 属于这种）。要满足 3.65V ÷ (2R + Ron) ≈ 58mA，
  可得 R ≈ 30Ω。此时 **P = 0.058² × 30 = 0.10W，0402（62.5mW）不够**，按规则 00 ② 逐档往上：
  0603（100mW）余量为 0，也不行；**最终用 0805（125mW）**。
- 在手册确认之前，按情况 B 留 0805 焊盘。

## 4. 主动均衡：分立开关电容（03_balancer）—— v0.3 方案 B（用户 2026-09-26 选定）

> 历史：v0.2 MP2645A ×2（买不到）→ v0.3 初 MP2643 ×7（均衡部分约 ¥186/块，太贵）→ **本方案约 ¥35/块**（10 块档，全部嘉立创料）。

### 4.1 原理

```
节点 V0(BAL0)…V8(BAL8)；每节电芯 k（V(k-1)..Vk）一个互补半桥，输出 Xk：
    QPk（AO3415A，S=Vk）  ─┬─ Xk          共栅 Gk ← UDk（74LVC1G17，VCC=Vk，GND=V(k-1)）
    QNk（AO3400A，S=V(k-1)）┘
    Gk = 低 → QPk 通 → Xk = Vk；   Gk = 高 → QNk 通 → Xk = V(k-1)
飞电容 CFk（3×100µF）接在 Xk 与 X(k+1) 之间（k = 1..7）：
    相位 1（全部 G 高）：Xk = V(k-1)、X(k+1) = Vk → CFk 并在第 k 节上
    相位 2（全部 G 低）：Xk = Vk、X(k+1) = V(k+1) → CFk 并在第 k+1 节上
```

全部 8 个半桥**同相**切换，每个飞电容轮流并到相邻两节上，电荷自动从电压高的一节流向低的一节，**无需判断方向**。
电流 ≈ ΔV / R_eq，与相邻两节的压差成正比（`tools/bms_calc.py` 的 `sc_equalizer`）：

| 相邻压差 | 10mV | 30mV | 100mV | 300mV |
|---|---|---|---|---|
| 估算电流（50kHz，3×100µF，单管，含 2 只保险丝冷阻） | 18mA | 55mA | **0.18A** | 0.55A |

R_eq ≈ √(R_SSL² + R_FSL²) = √(0.133² + 0.532²) ≈ 0.55Ω，其中 R_SSL = 1/(f·C_eff)，C_eff 取 3×100µF 在 3.6V 偏置下约 150µF；
R_FSL = 4 × (R_N + R_P + 0.015Ω + 2×保险丝冷阻 0.020Ω)，AO3400A/AO3415A 在栅压约 3.3V 时约 36/42mΩ。
（降本排查指出每相回路经过 2 只 BAL 节点保险丝，已计入；**保险丝冷阻是选型约束**，48mΩ 级的便宜保险丝会让电流再降约 25%。）
增强选项：每节 N、P 各并一只 + 时钟提到 100kHz，电流约再提高 60–80%，每块多约 ¥9（未采用）。

### 4.3 时钟传递与失效安全

- 第 k 节缓冲器的输出摆幅是 V(k−1)..Vk，经 1nF 耦合到第 k+1 节缓冲器输入（偏置在 Vk..V(k+1) 的中点），
  每一级都**非反相**，所以 8 个半桥同相。
- MCU 停止 PWM → 各级输入回到偏置中点，施密特迟滞保持最后状态 → 半桥静止在一个相位，飞电容只并在固定的一节上，**无持续电流**。
- MCU 复位（GPIO 高阻）同理停止。**不需要光耦**。
- 静态功耗：每节缓冲器 ≤ 10µA（手册最大值）+ 偏置 1.6µA，各节基本相同，不引入明显的不均衡漏电【实测校核】。
- **直通风险**：N/P 共栅，切换瞬间两管会短暂同时导通。74LVC1G17 边沿约 3ns，重叠时间极短；若实测直通损耗偏大，
  改为 N/P 分开驱动并加死区（每节多一颗缓冲 + RC）。

### 4.4 约束与保护（固件，`firmware/src/bms_logic.c`）

- 只在**顶部区**（最高节 ≥ 3.40V 且压差 ≥ 30mV）或**静置 30min 且压差 ≥ 80mV** 时输出 BAL_CLK；压差 ≤ 10mV 停止。
  开关电容只能按电压拉平，所以不能在 LFP 平台区常开。
- **压差 > 300mV 禁止均衡**（坏电芯或采样断线时电流会达安培级），只告警。
- **任一节 < 3.0V 禁止均衡**（半桥栅压取自本节电芯，过低时 MOSFET 导通不充分）。
- 主动均衡结束后仍由 MP2797 内部 58mA 被动均衡做 mV 级微调。
- 单元测试 37/37：含顶部起停、平台区不开、压差异常禁止、低压禁止、静置、故障停止，以及电荷交换仿真（90mV → 10mV 收敛）。

### 4.5 布局要点

- 每节的半桥、缓冲器、去耦放在一起，按电芯顺序排成一列；**各节的本地参考不同（V0..V7）**，这一列跨 8 个电位，
  相邻节之间只有飞电容和 1nF 耦合电容相连。
- 飞电容与两个半桥输出之间的回路尽量短而宽（均衡电流 ≤ 1A，走线 ≥ 0.5mm）。
- 时钟耦合线远离功率 MOSFET 和分流器采样线。

### 4.6 性能说明（与 MP2643 方案对比）

- **优点**：均衡部分约 ¥35/块（MP2643 方案约 ¥186/块），全部嘉立创现货、大部分是基础库；无客供件、无光耦；固件简单。
- **缺点**：电流随压差减小（100mV 时约 0.18A），120Ah 电芯 5% SOC 偏差（6Ah）需要约 35 小时的累计顶部均衡时间；
  平台区基本不搬。适合**同批次、一致性好的电芯**做日常维护；电芯离散度大时应回到 MP2643 方案。

## 10. 立创选料结论
