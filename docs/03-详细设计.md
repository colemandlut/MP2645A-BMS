## 2. 功率回路（01_power_path）

### 2.1 拓扑：高边、背靠背、**共漏**（用户 2026-09-27 按 MP2797 手册 Fig 26 p.121 / Fig 27 p.122 改定）

```
BAT+ ─F1─┬─ S[Q7..Q12 CHG]D ─┬─ FET_MID ─┬─ D[Q1..Q6 DSG]S ─┬─ PACK+
         │  (栅极参考=BAT+侧) │ (漏极公共点)│ (栅极参考=PACK+)  │
      TVS D3            Gate CHG_G    VMID←R214   Gate DSG_G      TVS D1,D2 + C1–C4 + C_PACK_E 47µF
BAT- ─────────── RS1 100µΩ ────────────────────────────────── PACK-
  (GND 单点, Net-Tie)  ↑SRP(电池侧)   ↑SRN(PACK− 侧)
```

- **CHG 管放电池侧，源极朝 BAT+**：关断时体二极管方向 BAT+→FET_MID，只能放电不能充电。
  **DSG 管放 PACK 侧，源极朝 PACK+**：关断时体二极管方向 PACK+→FET_MID，只能充电不能放电。
- **FET_MID 是两组的漏极公共点**，经 R214 100Ω 接 MP2797 的 VMID（电荷泵参考，VCP = VMID + 14.7V）。
- **栅极网络参考各自的源极**（手册 RCHG_PUP/DCHG_VGS 回电池正、RDSG_PUP/DDSG_VGS 回 PACK+；驱动器关断电平 CHG 参考 VTOP、DSG 参考 PACKP，p.14–15）：
  R_PUP1、DZ1、Q17 集电极接 **CHG 源极母线（BAT+ 侧）**；R_PUP2、DZ2、Q18 集电极接 **PACK+**。
- 旧版（v0.3 前）是「DSG 在电池侧、共源、两组栅极以 FET_MID 为参考」：两管全关时会被驱动器把某组栅极顶开、DZ 长期过流（论证见 `design/02_afe-spec.md` §6.2），已废弃。
- 待机模式（p.22）经 CHG 管体二极管导通，与本拓扑一致。

### 4.1 原理

```
板内节点 VB0…VB8（= BAL0…BAL8 经 F300–F308 之后）；每节电芯 k（VB(k-1)..VBk）一个互补半桥，输出 Xk：
    Q31k（AO3415A，S=VBk） ─┬─ Xk     GPk ← R32k 330Ω ∥ D31k（快关）← DRVk
    Q30k（AO3416， S=VB(k-1)）┘         GNk ← R31k 330Ω ∥ D30k（快关）← DRVk
    DRVk = U30k（74LVC1G17，VCC=VBk，GND=VB(k-1)）的输出
    DRVk 高 → Q30k 通 → Xk = VB(k-1)；  DRVk 低 → Q31k 通 → Xk = VBk
    每节本地储能 C31k 100µF 跨 VB(k-1)–VBk（线束只流直流）
飞电容 C33k ∥ C34k（2×100µF）接在 Xk 与 X(k+1) 之间（k = 1..7）：
    相位 1（全部高）：CFk 并在第 k 节上；  相位 2（全部低）：CFk 并在第 k+1 节上
时钟：BAL_CLK → R300 1k → C321 1nF → IN1；DRV(k-1) → C32k 1nF → INk；每节 R30k 100k 下拉到本节负极
```

全部 8 个半桥**同相**切换（每级都不反相），每个飞电容轮流并到相邻两节上，电荷自动从电压高的一节流向低的一节，**不用判断方向**。

**均衡电流**（`tools/bms_calc.py` 的 `sc_equalizer`，口径见规格书 §6.1，用户 2026-09-27 采纳）：

- 板上：R_SSL = 1/(f·C_eff) = 1/(75kHz × 100µF) = 0.133Ω（2×100µF 在 3.3V 偏置下有效约 100µF，样板实测）；
  R_FSL = 4 × (R_N 0.020 + R_P 0.042 + ESR/走线 0.015) × 1.08（死区修正）= 0.333Ω；R_板 = √(R_SSL² + R_FSL²) = 0.358Ω。
- 线束：有本地储能后线束只流直流，中间那根 BAL 线流 2I、两侧各 I，折算为 **6·R_w** 串联。R_w = 保险丝冷阻 23mΩ + 导线（0.5m 20AWG 约 17mΩ）+ J6 接触 + PCB ≈ 45mΩ，6·R_w = 0.27Ω。
- I = ΔV / (R_板 + 6·R_w) = ΔV / 0.628Ω。

| 相邻压差 | 10mV | 30mV | 100mV | 300mV |
|---|---|---|---|---|
| 典型（25°C） | 16mA | 48mA | **0.16A** | 0.48A |
| 热态 60°C / 最坏（最大 Rds、85°C、C 偏低） | 14 / 12mA | — | 0.14 / 0.12A | 0.43 / 0.37A |

- 原文的 0.19A 未计导线与端子电阻，已作废（用户 2026-09-27 改为 0.16A 口径）。
- 线束越短越粗电流越大：18AWG、≤0.3m 时约 0.18A@100mV；线束电阻为 0 时的上限约 0.28A。

### 4.3 时钟传递、死区与失效安全

- **死区（用户 2026-09-27 采纳 U-1）**：一个 74LVC 要驱动 N、P 两管的栅极，约 3.2nF（Qg 合计约 10.5nC），输出内阻 16–29Ω，边沿约 50–90ns，而不是手册 50pF 负载下的 2.9ns。
  共栅直驱时两管在这段时间里同时导通，估算直通峰值约 10A、每节 0.1–0.2W，而且各节不相等，会造成节间偏差。
  现在每个栅极接 330Ω（慢开）并联肖特基（快关），典型死区 20–50ns，最坏角点只剩阈值附近的小电流重叠。代价是 R_FSL 约 +8%（已计入 4.1）。
- **逐级交流耦合**：第 k−1 节的输出摆幅 VB(k−2)..VB(k−1)，经 1nF 耦合到第 k 节输入。输入只有 100k 下拉到本节负极，低于地的半波被 74LVC 输入对地钳位二极管拉住，所以输入实际摆幅约 −0.3V .. V_cell−0.3V。
  高电平比 VT+ 最大值高 0.4V 以上（发送节 3.0V、接收节 3.3V 这一最坏情况），低电平比 VT− 最小值低 1.2V。τ = 100k × 1nF = 100µs，75kHz 下下垂约 6%，**BAL_CLK 不能低于约 20kHz**。
- **首级也交流耦合，VB0 不接 GND（U-3）**：板上 GND 是分流器电池侧的 BAT−，VB0 是 BAL0 线束接的电芯 1 负极。两者在板上相连，BAL0 线束就和 200A 主回路并联，会分走约 0.8A。所以本页不用 GND，只用 BAL0..8 与 BAL_CLK。
- **失效安全（U-2）**：原方案「输入偏置到中点、靠迟滞保持最后状态」不成立（VCC 3.0V 时 VT+ 最小 1.48V，低于中点 1.50V；输入漏电 ±1µA 流过 500k 还有 ±0.5V 偏移）。一旦出现「第 k 节高、第 k+1 节低」，CFk 会长期跨在两节上（6.0–7.3V，超过 6.3V 额定）。
  现在是只接下拉：
  - MCU 停 PWM（停在低电平），或 MCU 复位（05 页 R52 100k 下拉），各节都回到**全低**：所有 P 管导通，CF1–CF7 分别并在第 2–8 节上，**无持续电流**，每颗飞电容只承受一节电压。
  - BAL_CLK 卡在高电平（MCU 死机）时，各节输入以 100µs 的时间常数衰减，也回到全低。其间最多约 30µs 的短暂混相。
  - **不需要光耦**。
- **静态功耗**：每节 74LVC 的 ICC ≤ 1µA（25°C），下拉电阻 0 电流。唯一的不对称是第 1 节上没有飞电容，少一份 MLCC 漏电，规格上限约 13µA，实际小一个数量级，可以忽略。
- **均衡运行时**：栅极驱动约 2.6mW/节（每节电芯 0.8mA），各节基本一致。整板功耗 100mV 时约 50mW，300mV 时约 0.2W。

### 4.4 约束与保护（固件，`firmware/src/bms_logic.c`）

- 只在**顶部区**（最高节 ≥ 3.40V 且压差 ≥ 30mV）或**静置 30min 且压差 ≥ 80mV** 时输出 BAL_CLK；压差 ≤ 10mV 时停止。开关电容只能按电压拉平，所以不能在 LFP 平台区常开。
- **压差 > 300mV 禁止均衡**，只告警。坏电芯或采样断线时电流可达安培级：1.3V 压差时约 2A，中间那根线流 4A，超过 3A 保险丝。
- **任一节 < 3.0V 禁止均衡**：半桥栅压取自本节电芯。
- 主动均衡结束后，仍由 MP2797 内部被动均衡做 mV 级微调（33Ω 串阻时典型 39mA、最大 45mA）。
- 单元测试：含顶部起停、平台区不开、压差异常禁止、低压禁止、静置、故障停止，以及电荷交换仿真（90mV → 10mV 收敛）。
- **规格书 X-5 的固件待办（尚未改代码）**：
  - BAL_CLK 保持 50–100kHz、50%；
  - 停时钟时停在低电平（TIM1 空闲电平 OIS1 = 0）；
  - 保留 IWDG；
  - 新增「均衡开着但相邻压差不下降」告警。BAL 线断、保险丝熔断、驱动失效，都只能这样发现，因为采样线是另一套，读 CELL 电压看不出来。

### 4.5 布局要点

- 8 节按电芯顺序排成一列：J6 在板边，F300–F308 靠近 J6。每节的半桥、本地储能 C31k、缓冲器、去耦、R-D 网络放在一起，C31k 紧贴两管源极。
- **各节的本地参考不同（VB0..VB7）**。相邻节之间只经飞电容和 1nF 耦合电容相连；均衡区不打 GND 过孔，VB0 不接 GND。
- 飞电容与两个半桥输出之间的回路尽量短而宽（最大约 1A，走线 ≥ 0.6mm）。
- 时钟耦合线远离功率 MOSFET 和分流器采样线；CELL 线与 BAL 线在板上完全分开。

### 4.6 性能说明（与 MP2643 方案对比）

- **优点**：均衡部分约 ¥40/块（MP2643 方案约 ¥186/块），全部嘉立创现货，大部分是基础库；无客供件、无光耦；固件简单。
- **缺点**：电流随压差减小（100mV 时约 0.16A）。120Ah 电芯 5% SOC 偏差（6Ah），按 0.16A 算需要约 **38h**（计 95% 效率约 39.5h）的累计顶部均衡时间；平台区基本不搬。适合**同批次、一致性好的电芯**做日常维护，电芯离散度大时应回到 MP2643 方案。

## 10. 立创选料结论

完整料表见 `docs/04-立创选料.md`（29 项，全部来自立创/LCSC 的搜索结果，没有打开过商品页）。对设计的主要影响：

- **主动均衡最终改为分立开关电容**（v0.3 方案 B）：MP2645A 买不到，MP2643 需 MPS 客供且约 ¥186/块，开关电容约 ¥35/块、全部嘉立创料。
- 分流器：立创上没有同时满足 0.1mΩ、≥10W、4 端子、锰铜的料，本版选业展 ASR-S-7-0.1F（C6075508，15W、2 端子，降本采用），并用 NTC_SHUNT 做温漂补偿。精度不够的话，就从立创以外的渠道买 4 端子锰铜分流器，这需要你来决定。
- 嘉立创库存、基础库/扩展库、单价：已可用 `python3 tools/jlc_api.py <C编号>` 直接查询（嘉立创 SMT 料号接口），成本见 `docs/05-成本估算.md`。
