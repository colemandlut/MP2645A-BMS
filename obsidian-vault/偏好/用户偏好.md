# 用户偏好

- 必须使用汉语回复
- 每条回复前加时间戳
- 测试跑完要通知
- 用 Obsidian 作为永久记忆知识库，每次回复前先检索本知识库（本目录 `obsidian-vault/`）

## PCB 工作流
- 用户有自定义技能 `pcb-workflow`（嘉立创EDA Pro + KiCad），任何原理图定稿/PCB/导出制造文件任务前必须加载并严格遵守
- 要点：画图 gpt-6-astra(codex) / 复核 Opus 5（不同厂商）；每次导出跑五维并行审查（闸口 A/B）；四层板 顶信号/内1 GND/内2 电源/底信号；泪滴强制；电感下方全层禁铜
- 云端容器无 KiCad / codex / 嘉立创EDA，这些步骤需在用户本机（macOS）执行
