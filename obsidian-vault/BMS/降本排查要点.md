# 降本排查要点（2026-09-26，详见 docs/06-降本排查.md）

- 基于 v0.3 方案 B（开关电容均衡）BOM；MP2643 相关料已作废，不再评估。
- 推荐项合计：10 块档每块省约 ¥15.0，100 块档约 ¥10.3；扩展库 25→23 种。
  - RS1 → 业展 ASR-S-7-0.1F（C6075508，5930 封装，需换封装）
  - QP → AO3415A（C5350990，36mΩ@2.5V），Q17/18 → SS8550（C8542，基础库），Y1 → 12MHz C9002（基础库，需改 PLL）
  - J5 → ZX-XH2.54-13PZZ（C22366169，封装实测 2.50mm，顺带修复 C158025 的 2.54 错误）；J7 → C7429634；J6 → XDWF-C3030WV-2*5P（C18202166，针号为之字形）
  - D4/D5 → 1N5819WS（C191023，基础库），C_LDO → C52923（0402）
- 教训：开关电容均衡回路每相经过 2 只 BAL 保险丝，保险丝冷阻必须当作选型约束（≤25mΩ）。48mΩ 的便宜 1206 保险丝会让均衡电流降 25–30%。
- MP2797 手册 Table 18：CVCP 47nF（额定电压按 80V×N/16 折算）、CVMID 需 100V、REGIN 需外置 NPN（FZT853TA）和 3.3µF；RSENSE 推荐 0.2–5mΩ。当前 BOM 与这些要求不一致，待设计方确认。
- 查料技巧：jlc_api 请求体加 `componentLibraryType:"base"` 可以只搜基础库；候选封装用 easyeda2kicad 取到 scratchpad 再跑 fp_compare，不会污染工程库。

## 第二轮（2026-09-26 12:40，电源、CAN、MP2797 补全）
- D6 SMBJ33A C78419 的嘉立创库存只有 47，必须换：晶导微 C353366（库存 7.7 万）。也可以考虑直接删掉 D6，因为 BAT+ 上已有 D3。
- C_IN_E 原 Panasonic 50V 低于 53V 浪涌，改 63V 的 C48971005（¥0.39）。C_IN1 改 2×C13832，少一种扩展库。C_OUT1 改基础库 C59461（22µF 6.3V 0603）。
- LMR16006 的 Tokmas 兼容件 C54823941：引脚相同、绝对最大 65V，但 Iq 80µA（TI 28µA）、600kHz，列为可选。其他 60V buck 都因 Iq 太大或更贵被否。
- SN65HVD230：R_RS=10k 接地是斜率控制模式，不是高速模式。HGSEMI 兼容件 C55259679 列为可选。
- MP2797 按 Table 18 补全：新增约 20 颗，10 块档 +¥2.55/块，100 块档 +¥1.05/块，扩展库净 +2 种（CVTOP 470nF/100V、CPACK 10nF/100V、3.3V 稳压管）。CVCP 用 47nF/50V 基础库 C1622，CVMID 用 100nF/100V 基础库 C28233，REGIN 的 NPN 用 MMBT5551 C2145（负载 ≤5mA 时可用）。
- 分流器 0.2mΩ 用 C469442（锰铜，±100ppm，¥2.63）：符合手册 0.2–5mΩ，发热 8W@200A；硬件 OCD 400A 正好落在 RNG0 满量程上，要改用 RNG1；单侧 MOS 导通时限流只有 87.5A。
- 全部采纳后总账：推荐 + 补全，10 块档 ≈ ¥185，100 块档 ≈ ¥143；再加上所有可选项 ≈ ¥167 / ¥131。
- MP2797 的 VTOP 下限 18V，8S LFP 的欠压阈值要留裕量。
