# 降本排查要点（2026-09-26，详见 docs/06-降本排查.md）

- 基于 v0.3 方案 B（开关电容均衡）BOM；MP2643 相关料已作废，不再评估。
- 推荐项合计：10 块档每块省约 ¥15.0，100 块档约 ¥10.3；扩展库 25→23 种。
  - RS1 → 业展 ASR-S-7-0.1F（C6075508，5930 封装，需换封装）
  - QP → AO3415A（C5350990，36mΩ@2.5V），Q17/18 → SS8550（C8542，基础库），Y1 → 12MHz C9002（基础库，需改 PLL）
  - J5 → ZX-XH2.54-13PZZ（C22366169，封装实测 2.50mm，顺带修复 C158025 的 2.54 错误）；J7 → C7429634；J6 → XDWF-C3030WV-2*5P（C18202166，针号为之字形）
  - D4/D5 → 1N5819WS（C191023，基础库），C_LDO → C52923（0402）
- 教训：开关电容均衡回路每相经过 2 只 BAL 保险丝，保险丝冷阻必须当作选型约束（≤25mΩ）。48mΩ 的便宜 1206 保险丝会让均衡电流降 25–30%。
- MP2797 手册 Table 18：CVCP 47nF（额定电压按 80V×N/16 折算）、CVMID 需 100V、REGIN 需外置 NPN（FZT853TA）和 3.3µF；RSENSE 推荐 0.2–5mΩ。当前 BOM 与这些要求不一致，待设计方确认。
- 查料技巧：jlc_api 请求体加 `componentLibraryType:"base"` 可以只搜基础库；候选封装用 easyeda2kicad 取到 scratchpad 再跑 fp_compare，不会污染工程库。
