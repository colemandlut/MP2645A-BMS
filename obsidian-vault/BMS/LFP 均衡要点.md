# LFP 均衡要点

- LFP OCV 平台 3.28~3.33V 很平，平台区电压差 ≠ SOC 差 → 不要在平台区按电压均衡
- 主策略：顶部均衡（最高节 ≥3.40V 且压差 ≥30mV 启动，≤10mV 停止）
- 静置 30min 后压差 ≥80mV 可均衡，有电流立即退出
- 主动均衡线与采样线要分开，否则 A 级均衡电流造成采样误差
- 0°C 以下禁止充电（析锂）
- 大容量电芯靠主动均衡更快：120Ah 5% 偏差（6Ah）开关电容 @100mV≈0.21A 约 30h，50mA 被动约 120h

## 开关电容均衡（方案 B）画图前核定（2026-09-27 19:1x JST，Opus 规格书 design/03_balancer-spec.md）
- N/P 共栅直驱会直通：栅负载约 3.2nF、74LVC 输出内阻 16–29Ω → 边沿 50–90ns（不是 50pF 下的 3ns），直通峰值约 10A、每节 0.1–0.2W 且各节不等 → 需死区（330Ω×2 + 1N5819WS×2 慢开快关）
- 「停时钟后偏置中点 + 施密特迟滞保持」不成立：VCC=3.0V 时 VT+ 最小 1.48V < 中点 1.50V，输入漏电 ±1µA×500k=±0.5V → 可能停在「k 高 k+1 低」，飞电容长期跨两节 6–7.3V > 6.3V 额定 → 改为只接 100k 下拉 + LVC 输入钳位恢复直流，停时钟/复位都收敛到全低
- 首级不能以 GND=V0 直连（BAL0 线束会与 BAT− 主回路并联分流）→ 首级也交流耦合
- 每节需本地储能 100µF（线束 0.7µH 与 100nF 谐振 ±1V）
- 含线束电阻后 100mV 压差典型 0.16A（60°C 0.14A，最坏 0.12A），非 0.19A
- 板上 BAL 保险丝保护不了线束 → 线束电芯端另加保险丝
- 网络类 `/03_balancer/X*` 匹配不上：网表路径用图纸名「开关电容主动均衡」
